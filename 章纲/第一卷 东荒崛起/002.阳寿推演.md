# 002 阳寿推演

## 1. 章前施工单（核心）

| 检查项 | 内容 |
| :--- | :--- |
| **本章生活目标** | 把感染压下去，别在矿洞里烂死 |
| **外界阻碍（对立面）** | 矿场没有医疗；伤势加重；“求医”会暴露软肋被敲诈 |
| **行动与策略（关键动作）** | 第一次启动系统推演：用最小代价换取“止血/抑感染”的可执行方案 |
| **结果与反应（爽点/代价）** | 系统规则落地：信息与方案可买，但用寿命结算；主角获得能立即执行的“土法工艺”路线 |
| **资源变化** | 阳寿减少（明确数字）；得到可复制的配方雏形与工艺步骤 |
| **章末钩子** | 推演的“最优材料”指向昨日塌方处的异常矿纹，必须冒险去挖 |

## 2. 剧情细纲（镜头语言）

1.  **镜头一（铺垫）：** 夜里伤口跳痛、发热，主角计算“活下去的时间窗口”（字数占比 20%）。  
    *   *细节：* 体温、脉搏、矿洞湿冷；主角用算盘式思维把“死亡概率”拆成可控变量。  
2.  **镜头二（冲突）：** 旁人提供的“偏方”要价离谱且效果未知，监工随时抽查（字数占比 30%）。  
    *   *细节：* 偏方是烂草根/劣质药渣；矿奴互相提防；主角不敢露出“我需要救命”的姿态。  
3.  **镜头三（转折）：** 主角启动系统，明确“推演=寿命结算”，并选择可承受的消耗（字数占比 30%）。  
    *   *细节：* 系统条目用【】展示：代价、产物、风险；主角犹豫与落锤的瞬间必须利落。  
4.  **镜头四（回响）：** 主角按方案做出第一份“止血粉/抑感染膏”，效果立刻见效但痛感强烈（字数占比 10%）。  
    *   *细节：* 反应、灼痛、止血；主角咬牙忍，把“能活”当成收益兑现。  
5.  **镜头五（收束）：** 系统提示“最优材料在异常矿纹处”，主角决定今晚就去（字数占比 10%）。  
    *   *细节：* 主角把账本、工具藏好；给自己定规矩：寿命是本金，不能乱花。  

## 3. 信息与伏笔

*   **新增信息**：系统的支付方式与产出形态；推演给路线不包执行成功。  
*   **伏笔埋藏**：主角开始记录“寿命账”；异常矿纹与关键材料绑定。  
*   **伏笔回收**：无。
