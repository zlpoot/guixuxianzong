# 008 分成与庇护

## 1. 章前施工单（核心）

| 检查项 | 内容 |
| :--- | :--- |
| **本章生活目标** | 把“监工威胁”转化成“保护伞”，并留出反制空间 |
| **外界阻碍（对立面）** | 监工贪婪且多疑；矿奴不信任监工的参与；告密链仍在 |
| **行动与策略（关键动作）** | 设计分成结构与边界：配方不交、工艺拆分、库存控制；用“持续服务”锁住对手需求 |
| **结果与反应（爽点/代价）** | 生意合法化为“监工名下的灰产”；主角暂时安全但失去自由；代价是必须持续交付且承受更高曝光 |
| **资源变化** | 获得独立矿洞与有限豁免；主角交易网络扩大但受监工约束 |
| **章末钩子** | 监工突然要求“带货”：要把药卖到别的矿区，意味着主角要面对更大的人群与更大的风险 |

## 2. 剧情细纲（镜头语言）

1.  **镜头一（铺垫）：** 主角与监工谈判“分成比例、交付频率、惩罚条款”（字数占比 20%）。  
    *   *细节：* 条款要像合同：违约代价、验收方式；主角把自己从“人”谈成“项目”。  
2.  **镜头二（冲突）：** 监工试探要配方/要人，主角必须守住底线（字数占比 30%）。  
    *   *细节：* 监工提出“我派人盯着你做”；主角用工艺拆分与关键步骤不可见来化解。  
3.  **镜头三（转折）：** 主角给出“只能压制不能根治”的长期服务框架，反向锁住监工（字数占比 30%）。  
    *   *细节：* 把监工的隐患包装成“需要每月一次调理”；既抬价又控制节奏。  
4.  **镜头四（回响）：** 主角回到矿洞，内部团队分裂：有人怕、有人成了信徒（字数占比 10%）。  
    *   *细节：* 让合作者质疑：你是不是卖了我们；主角用“规则与利益”安抚。  
5.  **镜头五（收束）：** 独立矿洞到手，监工提出扩大销售的要求（字数占比 10%）。  
    *   *细节：* 钩子落在“跨矿区扩张=曝光”；主角必须开始真正的组织化。  

## 3. 信息与伏笔

*   **新增信息**：分成结构与工艺拆分思路；独立矿洞资源。  
*   **伏笔埋藏**：扩张将引来更高层的注意；内部团队的忠诚需要制度维持。  
*   **伏笔回收**：无。
