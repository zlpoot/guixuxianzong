# 007 三天隐患

## 1. 章前施工单（核心）

| 检查项                      | 内容                                                                                   |
| :-------------------------- | :------------------------------------------------------------------------------------- |
| **本章生活目标**            | 从“被抓”变成“能谈”，保住命与生意                                                       |
| **外界阻碍（对立面）**      | 监工以暴力与权力压迫；主角一旦交出配方就会被榨干再灭口                                 |
| **行动与策略（关键动作）**  | 用系统推演出监工的修炼隐患与弱点，反向建立谈判筹码                                     |
| **结果与反应（爽点/代价）** | 主角用一句句精准症状把对方吓住，完成地位逆转；代价是一次较大的寿命支出与更深的绑定风险 |
| **资源变化**                | 得到“监工的恐惧与需求”这一资源；主角掌握对手把柄，但也被对手盯死                       |
| **章末钩子**                | 监工提出条件：要么当他的私医，要么死；主角选择把生意变成“分成”                         |

## 2. 剧情细纲（镜头语言）

1.  **镜头一（铺垫）：** 监工召见，表面客气，实际先用暴力立规矩（字数占比 20%）。
    - _细节：_ 被提起来、被摁住、被搜身；权力的压迫要具体到动作。
2.  **镜头二（冲突）：** 监工逼要配方，威胁灭口，主角发现“硬扛必死”（字数占比 30%）。
    - _细节：_ 监工的贪与疑；主角必须克制恐惧，不能嘴硬。
3.  **镜头三（转折）：** 主角推演监工个体，代价落地；用“三天隐患”反杀谈判（字数占比 30%）。
    - _细节：_ 症状描述必须像刀子：阴雨隐痛、运功滞涩、夜间盗汗；一句句把对方逼出真实恐惧。
4.  **镜头四（回响）：** 监工从要杀变成要留，交易从“配方”变成“服务 + 分成”（字数占比 10%）。
    - _细节：_ 对方的逻辑：杀鸡取卵不如细水长流；主角顺势抬价但不贪。
5.  **镜头五（收束）：** 监工提出“期限与考核”，主角拿到短期庇护，也埋下长期枷锁（字数占比 10%）。
    - _细节：_ 钩子落在一句话：从此主角的命不只在矿场，也在监工手里。

## 3. 信息与伏笔

- **新增信息**：监工的修炼隐患；系统可用于“人物弱点推演”。
- **伏笔埋藏**：监工会把主角当资产管理；推演寿命支出开始变大。
- **伏笔回收**：无。
