# 006 监工嗅到味

## 1. 章前施工单（核心）

| 检查项                      | 内容                                                                     |
| :-------------------------- | :----------------------------------------------------------------------- |
| **本章生活目标**            | 把交易藏住，不让监工顺藤摸瓜                                             |
| **外界阻碍（对立面）**      | 监工加强抽查与搜身；矿洞里出现“被打得半死的告密者”                       |
| **行动与策略（关键动作）**  | 主角主动“切断可追踪证据”：分散库存、改交付方式、把账本做成双层口径       |
| **结果与反应（爽点/代价）** | 主角的第一场风控：在高压环境下维持运转；代价是部分订单作废、内部信任受损 |
| **资源变化**                | 交易从“现货”转向“凭证/记账”；主角识别出一条告密链线索                    |
| **章末钩子**                | 监工点名叫主角去见面：不是抓捕，而是“谈生意”                             |

## 2. 剧情细纲（镜头语言）

1.  **镜头一（铺垫）：** 监工抽查升级，矿奴人人自危（字数占比 20%）。
    - _细节：_ 搜身、翻铺位、砸罐子；用具体破坏展示“权力=随意”。
2.  **镜头二（冲突）：** 主角的库存差点暴露，内部有人慌了想跑路（字数占比 30%）。
    - _细节：_ 一个合作者失控，差点把所有人拖下水；主角必须压住。
3.  **镜头三（转折）：** 主角启动“风控模式”：库存分散、交付拆分、账本双层（字数占比 30%）。
    - _细节：_ 双层账本：对外是“欠工钱”，对内才是“欠药债”；口径统一可救命。
4.  **镜头四（回响）：** 矿奴第一次理解“制度能救命”，也第一次开始怕主角（字数占比 10%）。
    - _细节：_ 有人说主角冷血；有人说主角靠谱；矛盾要显出来。
5.  **镜头五（收束）：** 监工点名召见，语气异常温和（字数占比 10%）。
    - _细节：_ 召见不是立刻抓，而是“我听说你有好东西”；钩子要狠。

## 3. 信息与伏笔

- **新增信息**：告密链的存在；账本双层口径。
- **伏笔埋藏**：监工想要的不只是钱，还想要“控制权”；内部有人已动摇。
- **伏笔回收**：无。
