# 005 欠条即股权

## 1. 章前施工单（核心）

| 检查项 | 内容 |
| :--- | :--- |
| **本章生活目标** | 把“救命药”变成稳定的交易网络，不再靠运气 |
| **外界阻碍（对立面）** | 矿奴群体混乱，默认互坑；有人想白嫖；有人想告密换减刑 |
| **行动与策略（关键动作）** | 把欠条升级为“份额”：用统一口径、统一折算、统一违约代价建立信用体系 |
| **结果与反应（爽点/代价）** | 主角用制度压住人性；矿奴第一次看到“可以被组织起来”的希望；代价是他必须承担追责与分配矛盾 |
| **资源变化** | 形成一批可量化的“应收账款”；主角掌握矿区小半人的伤病与欠债信息 |
| **章末钩子** | 一个欠条被撕毁引发冲突，背后有人挑事：矿场开始闻到“钱味” |

## 2. 剧情细纲（镜头语言）

1.  **镜头一（铺垫）：** 主角给欠条定模板：矿石/劳力/信息三类债务如何折算（字数占比 20%）。  
    *   *细节：* 账本上写出折算表；强调统一口径，防止扯皮。  
2.  **镜头二（冲突）：** 第一次“坏账”出现：有人拿了药不认账，还煽动别人抢（字数占比 30%）。  
    *   *细节：* 冲突落在“谁来执行规则”；主角不能靠嘴赢。  
3.  **镜头三（转折）：** 主角用一招制度化反制：公开账本、设立担保人、让群体利益绑定（字数占比 30%）。  
    *   *细节：* 让几个人组成互保小组；坏账的代价由小组承担，小组就会自发约束。  
4.  **镜头四（回响）：** 群体秩序初步建立，矿奴开始主动汇报信息换“信用额度”（字数占比 10%）。  
    *   *细节：* 信息变成资源：巡查路线、仓库钥匙、监工脾气。  
5.  **镜头五（收束）：** 有人偷偷撕毁欠条引爆争端，背后出现“挑事的手”（字数占比 10%）。  
    *   *细节：* 主角意识到对手不一定是监工，可能是矿场内部的另一套利益集团。  

## 3. 信息与伏笔

*   **新增信息**：欠条模板与互保机制；信息也可被定价。  
*   **伏笔埋藏**：坏账与挑事者指向“告密链”；账本一旦曝光就是死。  
*   **伏笔回收**：无。
