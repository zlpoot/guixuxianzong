# 001 矿奴账本

## 1. 章前施工单（核心）

| 检查项 | 内容 |
| :--- | :--- |
| **本章生活目标** | 活过今天的份额，不被扣口粮 |
| **外界阻碍（对立面）** | 黑石矿场配额压榨 + 伤口感染 + 监工随手鞭打 |
| **行动与策略（关键动作）** | 用“账房思维”把矿场剥削算成账；在不推演的前提下先建立可控信息与人情网络 |
| **结果与反应（爽点/代价）** | 读者看清矿场利润结构与压迫逻辑；主角意识到“信息差”才是第一桶金；代价是伤势恶化、时间紧迫 |
| **资源变化** | 主角得到一份“矿区人情与伤病账本”的雏形；欠下一笔人情（有人递布/递水/递一点药渣） |
| **章末钩子** | 主角在塌方碎石里看到异常矿纹，直觉那里藏着“能撬动命运的东西” |

## 2. 剧情细纲（镜头语言）

1.  **镜头一（铺垫）：** 黑石矿场开场，矿奴日常与配额机制（字数占比 20%）。  
    *   *细节：* 光线、粉尘、喘息、鞭声；“不完成份额=扣口粮/下矿坑”的规则用一个倒霉矿奴兑现。  
2.  **镜头二（冲突）：** 主角受伤、感染风险上升，监工以“效率”为名加压（字数占比 30%）。  
    *   *细节：* 伤口恶化的具体感受；监工一句话就决定一群人的生死；同伴的冷漠与恐惧。  
3.  **镜头三（转折）：** 主角把剥削算成“成本-收益-折损率”的账，意识到矿场真正怕的不是反抗而是“账本暴露”（字数占比 30%）。  
    *   *细节：* 用几个可见的例子（口粮掺假、工具维护、矿奴折损）把矿场利润讲透；主角开始记录“谁欠谁、谁怕谁”。  
4.  **镜头四（回响）：** 主角用冷静的记录换来第一次“可控的小合作”（字数占比 10%）。  
    *   *细节：* 有人递来破布或药渣，条件是“记我一笔”；主角收下并立规则：只记事实，不许空口白条。  
5.  **镜头五（收束）：** 塌方后清理碎石，主角发现异常矿纹与伴生结构线索（字数占比 10%）。  
    *   *细节：* 石壁纹理像账本的分层；主角用指甲抠下一点粉末，尝到一丝不同寻常的灵气苦味。  

## 3. 信息与伏笔

*   **新增信息**：黑石矿场的配额/惩罚机制；矿场“利润率”来自口粮掺假与矿奴折损。  
*   **伏笔埋藏**：异常矿纹暗示伴生灵晶/特殊矿脉；主角的账本将成为后续组织与信用凭证。  
*   **伏笔回收**：无。
