# 003 伴生灵晶

## 1. 章前施工单（核心）

| 检查项 | 内容 |
| :--- | :--- |
| **本章生活目标** | 把“启动资金”挖出来，不被发现 |
| **外界阻碍（对立面）** | 异常矿纹区域危险（塌方/尸鼠/毒气）；同伴可能告密；监工巡查 |
| **行动与策略（关键动作）** | 以最小动静潜入挖掘；用账本逻辑设计“分赃与沉默契约” |
| **结果与反应（爽点/代价）** | 成功挖出少量伴生灵晶；代价是惊险与阳寿进一步结算；主角第一次掌握可交易的硬通货 |
| **资源变化** | 灵晶入手（明确数量区间）；新增一个可信但脆弱的合作者（矿洞少年/同伴） |
| **章末钩子** | 灵晶不够用，系统提示“要么扩大生产，要么建立信用”，主角选择先做“可复制的药” |

## 2. 剧情细纲（镜头语言）

1.  **镜头一（铺垫）：** 主角在白天把巡查路线、塌方位置记入账本（字数占比 20%）。  
    *   *细节：* 记录不是写字装逼，而是为了“可重复行动”；用一个小细节证明主角观察力。  
2.  **镜头二（冲突）：** 夜潜异常矿纹处，遇到危险（塌方松动/毒气/尸鼠动静）（字数占比 30%）。  
    *   *细节：* 声音、呼吸、手抖；危险逼近要具体，不能抽象。  
3.  **镜头三（转折）：** 主角用系统做一次“局部推演”规避致命点，代价明确（字数占比 30%）。  
    *   *细节：* 推演只解决关键一步，例如“往左三寸避开空腔”；代价用【】条目落地。  
4.  **镜头四（回响）：** 伴生灵晶到手，但带来的不是轻松，而是“怎么藏、怎么换、怎么不死”（字数占比 10%）。  
    *   *细节：* 藏在鞋底/矿镐柄/账本夹层；合作者眼里的贪与怕。  
5.  **镜头五（收束）：** 主角定下第一条规则：灵晶不用来买“短命的安全”，要换“可复制的杠杆”（字数占比 10%）。  
    *   *细节：* 账本上写下：本金、成本、折损率、回收期。  

## 3. 信息与伏笔

*   **新增信息**：伴生灵晶的价值与稀缺；矿场对“私藏灵物”的惩罚。  
*   **伏笔埋藏**：合作者的忠诚不稳；灵晶来源可能被顺藤摸瓜。  
*   **伏笔回收**：无。
