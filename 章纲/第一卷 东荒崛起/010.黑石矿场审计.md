# 010 黑石矿场审计

## 1. 章前施工单（核心）

| 检查项                      | 内容                                                                                    |
| :-------------------------- | :-------------------------------------------------------------------------------------- |
| **本章生活目标**            | 在“大人物抽查”里保住产线与账本，不被一锅端                                              |
| **外界阻碍（对立面）**      | 矿场上层/执法修士突击审计；伪药事件预热；监工要求主角背锅                               |
| **行动与策略（关键动作）**  | 用“标准与证据链”自保：公开最安全的口径，隐藏致命的账；反向让审计看到矿场自身的违法成本  |
| **结果与反应（爽点/代价）** | 第一场合规战：主角不靠拳头靠口径与证据活下来；代价是必须交出一部分利润/让渡一部分控制权 |
| **资源变化**                | 建立“验收与赔付”雏形；得到一条指向更大渠道的线索（谁在背后吃矿场利润）                  |
| **章末钩子**                | 审计结束后，真正的杀招才到：矿场要“换监工/清洗矿区”，主角的保护伞开始动摇               |

## 2. 剧情细纲（镜头语言）

1.  **镜头一（铺垫）：** 审计来临的预兆：巡逻变密、矿场封口、监工紧张（字数占比 20%）。
    - _细节：_ 监工让人毁证；矿奴被集中盘问；主角嗅到“要死人”。
2.  **镜头二（冲突）：** 审计者突击检查，盯上药与账，监工试图把主角推出去挡枪（字数占比 30%）。
    - _细节：_ 审计者的问法要专业：来源、批次、责任、伤亡；监工的甩锅要阴。
3.  **镜头三（转折）：** 主角抛出“验收口径”：承认有药但强调是“应急止血”，并拿出批次记录与失败品销毁证明（字数占比 30%）。
    - _细节：_ 用少量可公开的记录换信任；同时暗示矿场口粮掺假、过劳死等更大问题，把审计的矛头引走。
4.  **镜头四（回响）：** 审计者选择交易：要抽成/要控制，但暂时不杀；矿奴看主角的眼神变了（字数占比 10%）。
    - _细节：_ 主角第一次体验“合规不是正义，是价格”；矿奴第一次把他当靠山。
5.  **镜头五（收束）：** 审计走后，矿场上层宣布“整顿”，保护伞动摇（字数占比 10%）。
    - _细节：_ 钩子落在整顿名单：有人被拖走；主角意识到下一步必须更快、更狠。

## 3. 信息与伏笔

- **新增信息**：审计/合规的问法与手段；验收与赔付的雏形。
- **伏笔埋藏**：矿场上层的利益链；保护伞动摇意味着“逃亡倒计时”启动。
- **伏笔回收**：无。
