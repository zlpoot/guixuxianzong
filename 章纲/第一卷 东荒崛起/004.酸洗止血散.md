# 004 酸洗止血散

## 1. 章前施工单（核心）

| 检查项                      | 内容                                                                                    |
| :-------------------------- | :-------------------------------------------------------------------------------------- |
| **本章生活目标**            | 做出第一批“能卖命”的药，活下去并开始赚钱                                                |
| **外界阻碍（对立面）**      | 材料极差、条件简陋；失败就是中毒或暴露；矿奴不信任且付不起                              |
| **行动与策略（关键动作）**  | 把系统路线拆成“可在矿洞复刻的工艺”；用灵晶换必要材料，药先救命再收债                    |
| **结果与反应（爽点/代价）** | 第一次产品兑现：止血立竿见影；代价是剧痛/副作用与阳寿结算；主角在矿奴中建立“有效”的口碑 |
| **资源变化**                | 产出第一批药；形成第一批欠条（未来劳力/矿石/信息）                                      |
| **章末钩子**                | 有人带着重伤找上门：救不救？救了就会出名，出名就会被监工盯上                            |

## 2. 剧情细纲（镜头语言）

1.  **镜头一（铺垫）：** 主角搭建简陋“工位”，列出工艺步骤与风险控制（字数占比 20%）。
    - _细节：_ 破陶罐、矿粉、腐蚀酸液、沉淀；主角像在写工序卡。
2.  **镜头二（冲突）：** 第一批试制差点失控（冒烟、灼伤、气味引人注意）（字数占比 30%）。
    - _细节：_ 失败的具体后果；旁边有人惊恐想跑；主角压住，要求“别出声”。
3.  **镜头三（转折）：** 用系统做一次“关键参数校准”，把配方从“能用”变成“能量产”（字数占比 30%）。
    - _细节：_ 校准只解决最关键变量（比例/温度/沉淀次数）；代价明确。
4.  **镜头四（回响）：** 药效在一个矿奴身上兑现，围观者从怀疑变成渴望（字数占比 10%）。
    - _细节：_ 止血、生肌的可视化；痛感与灼烧提醒读者“没有白捡的好处”。
5.  **镜头五（收束）：** 主角立“欠条规则”：先救命，后记账；欠条不能用嘴开，要按手印（字数占比 10%）。
    - _细节：_ 欠条写成“份额”雏形：多少斤矿、多少天劳力、违约代价。

## 3. 信息与伏笔

- **新增信息**：药的工艺路线与可复制性；欠条规则初成。
- **伏笔埋藏**：药的副作用会被敌人抓住做文章；“重伤求救者”将引爆关注。
- **伏笔回收**：无。
