# 时间线设定

## 1. 世界历史时间线

### 1.1 远古时期（10万年前-5万年前）

| 时间 | 事件 | 影响 |
|:---|:---|:---|
| **10万年前** | 天道形成 | 世界诞生，灵气出现 |
| **8万年前** | 第一批修士出现 | 修炼体系萌芽 |
| **6万年前** | 境界体系确立 | 练气→筑基→金丹→元婴→化神 |
| **5万年前** | 第一次仙魔大战 | 修士数量锐减90% |

### 1.2 上古时期（5万年前-1万年前）

| 时间 | 事件 | 影响 |
|:---|:---|:---|
| **5万年前** | 知识革命开始 | 一群修士试图建立"开放知识"体系 |
| **4.8万年前** | 知识革命失败 | 参与者被杀，幸存者建立万卷楼 |
| **3万年前** | 土地改革开始 | 一群修士试图建立"平价土地"体系 |
| **2.8万年前** | 土地改革失败 | 参与者被杀，幸存者建立厚土宗 |
| **1万年前** | 第二次仙魔大战 | 修士数量再次锐减 |

### 1.3 中古时期（1万年前-1000年前）

| 时间 | 事件 | 影响 |
|:---|:---|:---|
| **5000年前** | 天衍宗第一任宗主穿越 | 带来现代知识 |
| **4800年前** | 天道石建成 | 算力中心建立 |
| **4500年前** | 第一任宗主消失 | 留下归墟系统 |
| **3000年前** | 四大财阀联盟形成 | 垄断体系建立 |
| **1000年前** | 散修联盟成立 | 底层反抗组织出现 |

### 1.4 近代时期（1000年前-现在）

| 时间 | 事件 | 影响 |
|:---|:---|:---|
| **500年前** | 丹鼎阁完成丹药垄断 | 丹药价格暴涨 |
| **300年前** | 灵宝阁完成灵器垄断 | 灵器价格暴涨 |
| **100年前** | 天衍宗完成算力垄断 | 算力收费开始 |
| **50年前** | 昆仑虚完成全家桶体系 | 生态封闭开始 |
| **现在** | 故事开始 | 主角登场 |

## 5. 时间线禁区

### 5.1 绝对禁区

| 禁区 | 说明 |
|:---|:---|
| **时间线随意修改** | 已发生的事件不能修改 |
| **人物年龄矛盾** | 人物年龄必须与时间线对应 |
| **事件顺序矛盾** | 事件顺序必须与时间线对应 |
| **历史事件矛盾** | 历史事件必须与时间线对应 |

### 5.2 写作注意事项

```
【时间线写作规则】

1. 每个事件必须有明确的时间
2. 人物年龄必须与时间线对应
3. 事件顺序必须与时间线对应
4. 历史事件必须与时间线对应
5. 主角成长必须有时间记录
6. 势力发展必须有时间记录
```
