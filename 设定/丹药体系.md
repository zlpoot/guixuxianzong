# 丹药体系

## 1. 丹药总览

### 1.1 丹药定义

丹药是修仙界的核心资源，决定了：
- 修炼速度
- 突破概率
- 战斗恢复
- 寿元延长

### 1.2 丹药分类

| 类型 | 说明 | 代表丹药 |
|:---|:---|:---|
| **修炼丹** | 提升修炼速度 | 聚气丹、凝气丹 |
| **突破丹** | 帮助境界突破 | 筑基丹、结金丹、凝婴丹 |
| **恢复丹** | 恢复灵气和伤势 | 回气丹、疗伤丹、造化丹 |
| **辅助丹** | 辅助功能 | 辟谷丹、解毒丹、洗髓丹、延寿丹 |

## 7. 丹毒机制
### 7.1 丹毒来源

| 来源 | 说明 |
|:---|:---|
| **杂质** | 丹药中的杂质积累 |
| **抗药性** | 长期服用同种丹药 |
| **炼制不当** | 炼制过程失误 |

### 7.2 丹毒危害

| 危害 | 说明 |
|:---|:---|
| **修炼停滞** | 丹毒积累导致修炼效率下降 |
| **突破失败** | 突破时丹毒发作，导致失败 |
| **经脉受损** | 严重丹毒导致经脉受损 |
| **寿元缩短** | 极严重丹毒导致寿元缩短 |

### 7.3 丹毒清除

| 方法 | 成本 | 效果 |
|:---|:---|:---|
| **自然排出** | 时间（数年） | 缓慢清除 |
| **洗髓丹** | 5000灵石 | 清除50%丹毒 |
| **化毒丹** | 1万灵石 | 清除80%丹毒 |
| **主角的无丹毒丹药** | 市场价×0.5 | 无丹毒 |

## 14. 丹药工业化
### 14.1 传统炼丹的问题

| 问题 | 说明 |
|:---|:---|
| **效率低** | 一炉只能炼制少量丹药 |
| **成本高** | 需要高级炼丹师、高级丹炉 |
