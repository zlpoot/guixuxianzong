### 3.5 绝望的死循环

```
【练气期的困境】

收入低 → 买不起丹药 → 修炼慢 → 耗尽寿命 → 老死在练气期

【打破困境的方式】

1. 加入宗门：获得宗门补贴，但要为宗门服务
2. 冒险：探索遗迹、猎杀妖兽，但死亡率高
3. 黑市：购买廉价丹药，但有丹毒风险
4. 主角的平价丹药：打破垄断，让练气期修士看到希望
```

### 8.2 战力对比规则

```
【战力对比规则】

1. 战力差距10倍：碾压（100战力可以轻松击败10战力）
2. 战力差距3倍：压制（100战力可以压制30战力）
3. 战力差距1.5倍：优势（100战力对70战力有优势）
4. 战力相当：五五开（需要看功法、法器、战斗经验）

【特殊情况】

1. 功法克制：可以弥补战力差距
2. 法器加成：好法器可以提升战力
3. 战斗经验：老手可以击败战力更高的新手
4. 主角光环：归墟系统可以推演最优战斗方案
```
