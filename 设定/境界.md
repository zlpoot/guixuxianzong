# 境界体系

> **核心概念**：境界 = 权限等级
>
> 修仙世界是一个"算力社会"，境界越高，权限越大。

---

## 1. 境界总览

| 境界 | 权限等级 | 寿元 | 人口占比 | 定位 |
|:---|:---|:---|:---|:---|
| **凡人** | 无权限 | 70-80岁 | 99% | 普通用户（未注册） |
| **练气** | 普通用户 | 100-120岁 | 90%（修士中） | 底层打工人 |
| **筑基** | 高级用户 | 200-250岁 | 9% | 中产阶级 |

| **化神** | 超级管理员 | 2000-3000岁 | 0.01% | 传说 |
| **渡劫** | root权限 | 5000岁+ | 极少 | 接近系统核心 |
| **大乘** | 系统管理员 | 万岁+ | 几乎没有 | 可修改部分规则 |

### 1.2 权限详解

| 权限等级 | 可访问资源 | 可使用功能 | 可调用算力 |
|:---|:---|:---|:---|
| **普通用户** | 基础功法、基础丹药 | 基础法术 | 极少 |
| **高级用户** | 高级功法、高级丹药 | 高级法术 | 较多 |

| **超级管理员** | 宗门全部资源 | 高级管理权限 | 可调用大量天道算力 |
| **root权限** | 接近天道核心 | 接近系统核心 | 接近无限 |
| **系统管理员** | 天道核心 | 可修改部分规则 | 无限 |

## 3. 练气期

### 3.1 基本信息

| 维度 | 设定 |
|:---|:---|
| **定位** | 修仙界的基石与耗材 |
| **权限等级** | 普通用户 |
| **寿元** | 100-120岁 |
| **人口占比** | 90%（修士中） |
| **分级** | 1-9层（每3层为一坎：初期/中期/后期） |

### 3.2 权限范围

| 维度 | 权限 |
|:---|:---|
| **可访问功法** | 凡级、黄级功法 |
| **可使用丹药** | 凡级、黄级丹药 |
| **可操控法器** | 凡级、黄级法器 |
| **可调用算力** | 极少（需付费） |
| **天劫频率** | 无 |

### 3.3 战力参照

| 阶段 | 能力 | 类比 |
|:---|:---|:---|
| **初期（1-3层）** | 身体强化，力举千斤，能发小火球 | 持枪特警 |
| **中期（4-6层）** | 灵气护体，身轻如燕，施展基础法术 | 武林高手 |
| **后期（7-9层）** | 法术瞬发，威力如手雷，操控法器 | 美国队长 |

### 3.4 绝望的死循环

```
【练气期的困境】

收入低 → 买不起丹药 → 修炼慢 → 耗尽寿元 → 老死在练气期

【打破困境的方式】

1. 加入宗门：获得宗门补贴，但要为宗门服务
2. 冒险：探索遗迹、猎杀妖兽，但死亡率高
3. 黑市：购买廉价丹药，但有丹毒风险
4. 主角的平价丹药：打破垄断，让练气期修士看到希望
```

## 8. 天劫：系统的防火墙

### 8.1 天劫本质

```
天劫 = 系统校验

目的：
- 防止越权
- 清除bug
- 维持系统稳定

本质：
天劫不是"天罚"，而是"系统校验"。
境界提升 = 权限升级。
系统需要校验你是否配得上这个权限。
```

### 8.2 天劫类型

| 天劫类型 | 触发条件 | 强度 | 通过率 |
|:---|:---|:---|:---|
| **小天劫** | 金丹期每100年 | 中等 | 70% |
| **中天劫** | 元婴期每200年 | 强 | 50% |
| **大天劫** | 化神期每500年 | 极强 | 30% |
| **化神天劫** | 元婴→化神突破 | 恐怖 | 10% |
| **渡劫天劫** | 化神→渡劫突破 | 毁灭级 | 1% |

## 9. 境界与工业化

### 9.1 主角的革命

```
传统修仙：
- 境界 = 权限
- 权限被宗门垄断
- 底层永远无法升级

主角的革命：
- 不是推翻境界体系
- 而是让权限更容易获取
- 让底层人也能升级

本质：
修仙互联网革命
算力民主化
```

### 9.2 五次工业革命对境界的影响

| 革命 | 对境界的影响 |
|:---|:---|
| **丹药流水线** | 降低练气→筑基成本 |
| **灵气能源** | 降低筑基→金丹成本 |
| **阵法计算机** | 降低金丹→元婴成本 |
| **灵票金融** | 让底层也能获得资源 |
| **算力革命** | 让每个人都能接入天道石 |
