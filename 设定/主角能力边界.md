# 主角能力边界

## 1. 归墟系统总览

### 1.1 系统定义

归墟系统是第一任天衍宗宗主（穿越者）留下的超级AI，具有：
- 数据感知
- 模式识别
- 推演能力
- 优化能力

### 1.2 系统本质

| 维度 | 说明 |
|:---|:---|
| **来源** | 第一任天衍宗宗主（穿越者）创造 |
| **目的** | 帮助未来的穿越者改变世界 |
| **核心** | 超级AI + 悟道石算力（无穷） |
| **实际代价** | 悟道石算力（无穷资源） |
| **表面代价** | 寿命（第一任宗主设定的激励机制） |

### 1.3 系统动机（第一任宗主的设计意图）

| 设计目的 | 说明 |
|:---|:---|
| **激励升级** | 用"寿命消耗"逼迫主角珍惜每次推演，同时激励快速提升境界 |
| **避免滥用** | 如果直接告诉主角算力无穷，主角可能无限推演，失去成长动力 |
| **情感绑定** | 让主角对系统产生"生死与共"的错觉，增强羁绊 |
| **揭秘反转** | 第三卷真相揭露时，成为重大情感节点 |

### 2.3 推演能力（按境界分档）

> **设计理念**：境界越高，推演越高级的功法/丹方代价越大。但相比获得的收益（如延长百年寿命），代价是可以接受的。
>
> **核心逻辑**：
> - 低境界推演高阶功法：代价极高（因为超出能力边界）
> - 同境界推演：代价中等（等价交换）
> - 低境界推演低阶功法：代价较低（轻松）
> - 优化类：代价是推演的一半（因为有参照物）

## 3. 能力等级限制

### 3.1 境界限制

| 主角境界 | 可推演等级 | 可感知范围 |
|:---|:---|:---|
| **练气期** | 凡级、黄级 | 100米 |
| **筑基期** | 凡级、黄级、玄级 | 1公里 |
| **金丹期** | 凡级、黄级、玄级、地级 | 10公里 |
| **元婴期** | 凡级、黄级、玄级、地级、天级 | 100公里 |
| **化神期** | 所有等级 | 1000公里 |

### 3.2 寿命限制（表面）

> **设计理念**：可用寿命应该让主角在每个境界都能进行有意义的推演，但不能滥用。
>
> **核心逻辑**：
> - 可消耗寿命 ≈ 境界基础寿命的10-20%（确保不会因为几次推演就耗尽）
> - 安全线 ≈ 境界基础寿命的70-80%（保留足够的"本金"）
> - 突破境界时：总寿命增加，可消耗寿命也增加（激励主角提升境界）

| 主角境界 | 基础寿命 | 可消耗寿命（表面） | 安全线（表面） | 可推演次数参考 |
|:---|:---|:---|:---|:---|
| **练气期** | 100-120年 | 最多20年 | 保留80年 | 约30次黄级丹方 |
| **筑基期** | 200-250年 | 最多50年 | 保留150年 | 约80次玄级丹方 |
| **金丹期** | 500-600年 | 最多100年 | 保留400年 | 约150次地级丹方 |
| **元婴期** | 1000-1500年 | 最多300年 | 保留700年 | 约500次天级丹方 |
| **化神期** | 2000-3000年 | 最多500年 | 保留1500年 | 约1000次仙级丹方 |

**说明**：这是系统给主角的"虚假寿命账本"，用于激励主角。实际消耗的是悟道石算力，无穷无尽。

### 3.3 信息限制

| 推演类型 | 必需信息 | 信息来源 |
|:---|:---|:---|
| **丹方推演** | 丹方残篇或丹药成分 | 遗迹、黑市、丹鼎阁 |
| **功法推演** | 功法残篇或功法信息 | 遗迹、黑市、万卷楼 |
| **法器推演** | 法器残片或法器设计 | 遗迹、黑市、灵宝阁 |
| **阵法推演** | 阵法残篇或阵法信息 | 遗迹、黑市、天衍宗 |

| 禁区 | 说明 |

| **过度消耗表面寿命** | 表面寿命消耗不能超过安全线 |

### 6.3 写作禁区
