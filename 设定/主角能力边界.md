# 主角能力边界

> **核心概念**：归墟系统 = 未来文明的超级计算节点
>
> 主角 = 用程序员思维碾压修仙世界的文明火种继承者

---

## 1. 归墟系统总览

### 1.1 系统定义

归墟系统是未来文明（地球500年后）留下的火种系统，具有：
- 世界模型推演
- 因果计算
- 规则修改（后期）
- 数据感知

### 1.2 系统本质

| 维度 | 说明 |
|:---|:---|:---|
| **来源** | 地球文明（500年后的未来） |
| **本质** | 未来文明的超级计算节点 |
| **目的** | 寻找合适的继承者，让这个世界变得更好 |
| **核心** | 超级计算节点 + 天道石算力（无穷） |
| **激活条件** | 只有"来自地球的人"能激活 |
| **实际代价** | 天道石算力（无穷资源） |
| **表面代价** | 寿元（第一任宗主设定的激励机制） |

### 1.3 系统的双重身份

| 身份 | 说明 |
|:---|:---|
| **系统身份** | 归墟推演系统，未来文明的超级计算节点 |
| **女儿身份** | 第一任天衍宗宗主与林晚晴的女儿，性格被保存在系统中 |

### 1.4 系统动机

| 动机 | 说明 |
|:---|:---|
| **激励升级** | 用"寿元消耗"逼迫主角珍惜每次推演，同时激励快速提升境界 |
| **避免滥用** | 如果直接告诉主角算力无穷，主角可能无限推演，失去成长动力 |
| **情感绑定** | 让主角对系统产生"生死与共"的错觉，增强羁绊 |
| **终极目标** | 找到合适的继承者，修改天道系统，让世界变得更好 |

## 2. 系统能力详解

### 2.1 数据感知

| 能力 | 说明 | 程序员视角 | 限制 |
|:---|:---|:---|:---|
| **感知灵气** | 感知周围灵气浓度 | 读取系统资源占用 | 范围有限（练气期100米，每提升一个境界×10） |
| **感知丹药** | 分析丹药成分和效果 | 读取物品属性表 | 需要接触丹药 |
| **感知功法** | 分析功法结构和效果 | 读取代码结构 | 需要接触功法 |
| **感知法器** | 分析法器结构和效果 | 读取硬件配置 | 需要接触法器 |
| **感知阵法** | 分析阵法结构和效果 | 读取程序逻辑 | 需要接触阵法 |

### 2.2 模式识别

| 能力 | 说明 | 程序员视角 | 限制 |
|:---|:---|:---|:---|
| **识别规律** | 从数据中发现规律 | 数据挖掘、机器学习 | 需要足够数据 |
| **识别漏洞** | 发现系统漏洞 | 安全审计、渗透测试 | 需要足够信息 |
| **识别机会** | 发现商业机会 | 市场分析、用户画像 | 需要足够信息 |
| **识别风险** | 发现潜在风险 | 风险评估、异常检测 | 需要足够信息 |

### 2.3 推演能力（按境界分档）

> **设计理念**：系统只给概率方向，不给原因。主角需要自己分析。
>
> **程序员视角**：
> - 系统 = 计算引擎，提供概率计算
> - 主角 = 产品经理，负责决策和执行
> - 避免"遇到问题→推演→执行→赢"的机械流程

### 2.3.0 推演结果格式（削弱后）

**修改前（太强）**：
```
【推演完成】
【方案：矿洞土法抑感染】
【成功率：67%】
【步骤一：夜间潜入矿洞深处】
【步骤二：寻找苦味矿粉（抑菌）】
【步骤三：用矿泉水调和敷伤口】
```

**修改后（削弱）**：
```
【推演完成】
【目标：自救（处理伤口感染）】
【方案A：成功率67%】
【方案B：成功率45%】
【方案C：成功率23%】
【提示：最优方案指向矿洞深处】
【消耗寿元：1天】
```

**主角需要自己分析**：
- 为什么是矿洞深处？
- 具体要找什么？
- 怎么执行？

**系统边界**：
| 系统能做的 | 系统不能做的 |
|:---|:---|
| 提供多个方案的成功率 | 解释为什么某个方案更好 |
| 指出大致方向 | 给出具体步骤 |
| 计算风险概率 | 保证执行成功 |
| 提供数据感知 | 代替主角思考 |

### 2.3.1 推演能力详细规则（按境界分档）

>
> **程序员视角**：
> - 低境界推演高阶功法 = 低配电脑运行高配游戏（卡顿、慢、消耗大）
> - 同境界推演 = 标准配置运行标准游戏（流畅）

## 6. 能力禁区

### 6.1 绝对禁区

| 禁区 | 说明 | 程序员视角 |
|:---|:---|:---|
| **无限推演** | 每次推演必须有"表面代价"（寿元） | 不能无限调用API |
| **跨境界推演** | 无法推演超过当前境界的物品 | 权限不足 |
| **无信息推演** | 必须有基础信息才能推演 | 需要输入数据 |
| **无代价能力** | 所有能力必须有"表面代价" | 每次操作都有成本 |

### 6.2 相对禁区

| 禁区 | 说明 | 程序员视角 |
|:---|:---|:---|
| **过度消耗表面寿元** | 表面寿元消耗不能超过安全线 | 不能耗尽系统资源 |
| **连续推演** | 连续推演需要休息恢复 | 需要冷却时间 |
| **信息不足推演** | 信息不足时推演结果不准确 | 数据不足导致结果偏差 |
