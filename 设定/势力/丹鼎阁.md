# 丹鼎阁

> **核心概念**：丹鼎阁 = 丹药霸主 = 修仙界的"辉瑞+强生"
>
> 本质：垄断丹药，收割全修仙界的健康需求

---

## 2. 背景故事

### 2.1 丹药世家的阴谋

丹鼎阁不是某个"丹痴"创建的，而是一个**丹药世家**经过几代人的精心布局，逐步垄断了丹药市场。

| 阶段 | 时间 | 事件 |
|:---|:---|:---|
| **第一阶段** | 5000年前 | 丹药世家"丹家"开始收购小型丹坊 |
| **第二阶段** | 4000年前 | 丹家通过"价格战"挤垮竞争对手 |
| **第三阶段** | 3000年前 | 丹家与天衍宗合作，获得算力支持 |
| **第四阶段** | 2000年前 | 丹家改名为"丹鼎阁"，正式垄断丹药市场 |
| **第五阶段** | 现在 | 丹鼎阁控制了90%的丹药市场 |

### 2.2 垄断的套路

丹鼎阁的垄断不是偶然，而是几代人的精心策划：

| 步骤 | 手法 | 目的 | 程序员视角 |
|:---|:---|:---|:---|
| **收购** | 用高价收购小型丹坊 | 消除竞争对手 | 收购竞争对手 |
| **压价** | 短期内低价销售，挤垮剩余竞争者 | 形成垄断 | 恶性价格战 |
| **涨价** | 垄断后大幅涨价 | 收割消费者 | 订阅涨价 |
| **专利** | 将丹方专利化，禁止他人使用 | 维持垄断 | 专利壁垒 |

### 2.3 核心秘密

丹鼎阁的垄断不是靠技术，而是靠"资本运作"：

- 他们收购了所有有潜力的丹坊
- 他们用价格战挤垮了所有不肯出售的竞争者
- 他们与天衍宗合作，获得了算力优势
- 他们将丹方专利化，禁止他人使用

**真相**：丹鼎阁的本质是一个"资本集团"，他们不关心丹道，只关心利润。

### 2.4 丹毒的秘密

| 秘密 | 说明 |
|:---|:---|:---|
| **丹毒来源** | 丹毒是丹鼎阁故意保留的 |
| **目的** | 让修士必须持续购买丹药 |
| **机制** | 有丹毒的丹药 = 需要持续消费 |
| **程序员视角** | 计划性报废 |
