# 千机门

## 1. 基本信息

- **类型**：小型势力
- **核心能力**：制造术、炼器术
- **地位**：小型势力，擅长制造各种法器和工具
- **现状**：生意不好，勉强维持

## 2. 核心技术

| 技术 | 说明 |
|:---|:---|:---|
| **法器制造** | 各种低中阶法器的制造 |
| **工具制造** | 修炼辅助工具的制造 |
| **流水线技术** | 批量生产的雏形技术 |

## 3. 经营状况

- **现状**：生意不好，订单减少
- **原因**：市场竞争激烈、大势力挤压
- **门人**：部分弟子离开，核心还在
- **资产**：设备还在，但开工不足

## 4. 资源

| 资源 | 说明 |
|:---|:---|:---|
| **制造技术** | 核心传承，价值较高 |
| **生产设备** | 设备齐全，但利用率低 |
| **核心弟子** | 还在坚守 |

## 5. 与其他势力的关系

| 势力 | 关系 |
|:---|:---|:---|
| **丹鼎阁** | 竞争关系（丹炉制造） |
| **神机宗** | 技术上有交集（都涉及制造） |
| **灵宝阁** | 销售渠道之一 |

## 6. 与神机宗的区别

| 维度 | 神机宗 | 千机门 |
|:---|:---|:---|
| **核心能力** | 傀儡术 | 制造术、炼器术 |
| **覆灭原因** | 被大势力联合覆灭 | 无 |
| **现状** | 被追杀（暗中） | 生意不好，勉强维持 |
| **时间** | 五十年前 | - |
