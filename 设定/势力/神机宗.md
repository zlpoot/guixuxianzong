# 神机宗

## 1. 基本信息

- **类型**：落魄势力（已被覆灭）
- **核心能力**：傀儡术、机关术
- **曾经地位**：中型势力，擅长制造各种傀儡
- **覆灭原因**：研发出挖矿傀儡技术，威胁到大势力的利益

## 2. 核心技术

| 技术 | 说明 |
|:---|:---|
| **挖矿傀儡** | 可替代矿奴进行采矿，效率高、成本低 |
| **战斗傀儡** | 各种等级的战斗傀儡，从低阶到高阶 |
| **辅助傀儡** | 运输、侦查、防御等辅助功能 |

## 3. 覆灭经过

- **覆灭时间**：约五十年前（大多数人已遗忘）
- **覆灭势力**：多方大势力联合行动
- **覆灭原因**：挖矿傀儡技术威胁到矿场利益集团
- **幸存者**：极少数，核心传承者下落不明

## 4. 遗产

| 遗产 | 说明 |
|:---|:---|:---|
| **傀儡技术** | 核心传承，目前散落在外 |
| **傀儡图纸** | 部分被毁，部分被抢，部分下落不明 |
| **核心弟子** | 苏玲珑（神机宗宗主孙女） |

## 5. 与其他势力的关系

| 势力 | 关系 |
|:---|:---|:---|
| **丹鼎阁** | 无直接关系 |
| **天衍宗** | 参与覆灭神机宗的势力之一 |
| **昆仑虚** | 参与覆灭神机宗的势力之一 |
| **灵宝阁** | 曾是神机宗的销售渠道 |
