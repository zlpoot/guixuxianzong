# 天衍宗

## 1. 势力概述

| 维度 | 设定 |
|:---|:---|
| **势力名称** | 天衍宗 |
| **定位** | 算力霸主，修仙界的"专利局+搜索引擎" |
| **核心资源** | 天道石（推演核心）、功法库、丹方库 |
| **地理位置** | 中洲核心区域 |
| **势力等级** | 顶级势力（四大财阀之一） |

## 2. 背景故事

### 2.1 创建者

天衍宗由一位"穿越者"创建于5000年前。

这位穿越者来自一个叫"中国"的地方，他带着现代的"科学思维"和"共产主义理想"来到这个世界。他发现这个世界的人被宗门垄断压榨，于是创建了天衍宗，希望用"算力共享"改变世界。

### 2.2 理想的背叛

第一任宗主离开后，天衍宗逐渐背叛了他的初衷：

| 维度 | 第一任宗主的理想 | 现在天衍宗的做法 |
|:---|:---|:---|
| **算力** | 让所有人都能用上廉价算力 | 垄断算力，高价收割 |
| **知识** | 知识应该开放共享 | 知识专利化，收费收割 |
| **目标** | 让世界变得更好 | 用垄断维持统治 |

### 2.3 现状

现在的天衍宗，已经成为修仙界最大的"算力垄断者"。所有宗门的功法推演、丹方计算、阵法设计，都要向天衍宗付费购买算力服务。

## 3. 核心价值观

### 3.1 表面价值观

- "天道之下，众生平等（但付费优先）"
- "算力即真理"
- "知识有价，付费使用"

### 3.2 实际价值观

- 垄断即正义
- 收割即天经地义
- 利润高于一切

## 6. 核心资源：天道石

### 6.1 基本信息

| 维度 | 设定 |
|:---|:---|
| **名称** | 天道石 |
| **外观** | 一块巨大的晶体，散发着神秘光芒 |
| **位置** | 天衍宗核心禁地 |
| **本质** | 一台"服务器"（第一任宗主设计） |
| **功能** | 提供算力服务、功法推演、丹方计算 |

### 6.2 运作机制

天道石是一个"黑箱"：

```
【输入】客户需求 + 灵石支付
    ↓
【黑箱】天道石"神秘运算"
    ↓
【输出】推演结果

（天衍宗的人不知道原理，只知道"怎么用"）
```

### 6.3 限制设计

第一任宗主故意设计的"限制"：

| 限制 | 表现 | 真相 |
|:---|:---|:---|
| **算力上限** | 每次推演有上限 | 防止有人滥用算力 |
| **权限分级** | 只有高层能用核心功能 | 维持宗门等级制度 |
| **数据隔离** | 不同客户的数据不互通 | 防止信息泄露 |
| **后门锁定** | 核心功能被锁定 | 只有"管理员"能解锁 |

### 6.4 天衍宗的误解

3000年来，天衍宗一直在"误用"天道石：

- 天衍宗只知道"怎么用"，不知道"原理"
- 他们把天道石当成"神器"崇拜，不敢深入研究
- 他们不知道天道石有"后门"，更不知道有"管理员权限"
- 他们不知道有人在"免费使用"他们的算力

|:---|:---|:---|

### 8.2 核心设施

## 9. 与其他势力的关系

### 9.1 关系图谱

| 势力 | 关系 | 说明 |
|:---|:---|:---|
| **丹鼎阁** | 合作+竞争 | 丹鼎阁是天衍宗的大客户，但也依赖天衍宗的算力 |
| **灵宝阁** | 合作 | 灵宝阁需要天衍宗的阵法推演服务 |
| **昆仑虚** | 微妙 | 昆仑虚自研算力，但效率不如天衍宗 |
| **散修联盟** | 收割对象 | 散修买不起正版服务，只能用盗版 |

### 9.2 利益链条

```
【天衍宗】提供算力服务
    ↓
【丹鼎阁】用算力推演丹方 → 生产丹药 → 垄断丹药市场
    ↓
【散修】买不起正版丹药 → 只能用劣质丹药 → 永远翻不了身
```

## 10. 弱点与隐患

### 10.1 技术断层

- 天衍宗只知道"怎么用"天道石，不知道"原理"
- 如果天道石出问题，他们无法修复
- 他们不知道天道石有"后门"

### 10.2 内部腐败

- 高层垄断算力，中底层不满
- 商业化过度，失去了"道统"的威望
- 内部派系斗争激烈

### 10.3 外部威胁

- 昆仑虚在研发自己的算力系统
- 主角拥有天道石的"管理员权限"
- 散修对天衍宗的不满在积累

## 11. 在剧情中的作用

### 11.1 初期

- 主角通过归墟系统"免费使用"天衍宗的算力
- 天衍宗不知道有人在"薅羊毛"

### 11.2 中期

- 主角发现天衍宗背叛了第一任宗主的理想
- 主角与天衍宗产生冲突
- 天衍宗发现有人在"偷"算力，开始追查

### 11.3 后期

- 主角揭露天衍宗的真相
- 主角继承第一任宗主的遗产，成为天道石的"管理员"
- 天衍宗面临改革或覆灭
