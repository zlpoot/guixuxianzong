# 厚土宗

## 1. 势力概述

| 维度 | 设定 |
|:---|:---|
| **势力名称** | 厚土宗 |
| **定位** | 防御与建设专家，修仙界的"建筑公司+安保公司" |
| **核心资源** | 防御阵法、建筑技术、矿脉开采 |
| **地理位置** | 北原腹地，占据大片土地 |
| **势力等级** | 中等势力 |

## 2. 背景故事

### 2.1 土地改革的失败者

厚土宗不是某个"土痴"创建的，而是一群**土地改革失败者**的聚集地。

| 阶段 | 时间 | 事件 |
|:---|:---|:---|
| **第一阶段** | 3000年前 | 一群修士试图在北原建立"平价土地"体系 |
| **第二阶段** | 2800年前 | 改革失败，被四大财阀打压 |
| **第三阶段** | 2500年前 | 幸存者建立"厚土宗"，专注于防御和建设 |
| **第四阶段** | 1000年前 | 厚土宗成为修仙界最大的"建筑+安保"组织 |
| **第五阶段** | 现在 | 厚土宗表面中立，暗中支持散修联盟 |

### 2.2 土地改革的理想

3000年前，一群修士发现了一个问题：

| 问题 | 后果 |
|:---|:---|:---|
| **土地被垄断** | 灵脉、矿脉、药山都被宗门占据 |
| **散修无处容身** | 散修没有地方修炼，只能在荒野流浪 |
| **资源被收割** | 散修想用土地，就得向宗门交高额费用 |

这群修士决定在北原建立"平价土地"体系：

- 开垦荒地，让散修有地方修炼
- 建立公共设施，让散修有地方住
- 收取合理费用，让散修用得起

### 2.3 改革的失败

四大财阀不允许这种"破坏市场秩序"的行为存在：

| 打压手段 | 具体做法 |
|:---|:---|:---|
| **经济封锁** | 禁止向改革者出售丹药、灵器 |
| **武力镇压** | 派遣高手攻击改革者的据点 |
| **舆论抹黑** | 散布谣言，说改革者是"邪教" |
| **内部渗透** | 收买改革者的核心成员 |

改革持续了200年，最终失败。大部分改革者被杀，只有少数幸存者逃到北原深处。

### 2.4 厚土宗的建立

2500年前，幸存者建立了"厚土宗"：

| 表面 | 实际 |
|:---|:---|:---|
| 专注于防御和建设 | 保存实力，等待时机 |
| 接受四大财阀的订单 | 积累资源，暗中发展 |
| 表面中立 | 暗中支持散修联盟 |

### 2.5 核心秘密

厚土宗的本质是"理想主义者"：

- 他们曾经试图进行"土地改革"
- 他们失败了，但没有放弃理想
- 他们现在专注于防御和建设，但内心仍然支持"共同富裕"
- 他们暗中支持散修联盟，希望有一天能实现理想

**真相**：厚土宗的创始人是一群"土地改革者"。他们的理想是"让所有修士都能用上平价土地"，虽然失败了，但他们没有放弃。

### 2.6 现状

现在的厚土宗，已经成为修仙界最大的"建筑+安保"组织。所有需要建造宗门、布置阵法、开采矿脉的人，都会选择厚土宗。

## 3. 核心价值观

### 3.1 表面价值观
