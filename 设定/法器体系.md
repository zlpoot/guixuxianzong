# 法器体系

## 1. 法器总览

### 1.1 法器定义

法器是修士使用的武器、防具、辅助器具，通过灵力驱动，具有特殊功能。

### 1.2 法器分类

| 分类 | 说明 | 代表 |
|:---|:---|:---|
| **攻击法器** | 用于攻击的法器 | 飞剑、飞刀、法印 |
| **防御法器** | 用于防御的法器 | 护盾、护甲、护罩 |
| **辅助法器** | 辅助功能的法器 | 储物袋、飞行法器、传讯法器 |
| **特殊法器** | 特殊功能的法器 | 阵盘、傀儡、丹炉 |
