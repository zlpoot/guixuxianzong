# 功法体系

## 1. 功法总览

### 1.1 功法定义

功法是修士修炼的核心，决定了：
- 灵气吸收效率
- 灵气储存容量
- 灵气使用方式
- 战斗能力

### 1.2 功法分类

| 类型 | 说明 | 代表功法 |
|:---|:---|:---|
| **基础功法** | 修炼入门，决定灵气吸收效率 | 引气诀、聚灵功 |
| **战斗功法** | 战斗技能，决定战斗能力 | 火球术、御剑术 |
| **辅助功法** | 辅助功能，提升修炼效率 | 炼丹术、炼器术 |
| **特殊功法** | 特殊能力，稀有功法 | 分神术、瞬移术 |

## 6. 功法学习规则

### 6.1 学习条件

| 条件 | 说明 |
|:---|:---|
| **境界要求** | 功法有境界限制，低于要求无法学习 |
| **资质要求** | 部分功法需要特殊资质 |
| **资源要求** | 学习功法需要消耗灵石、丹药 |
| **时间要求** | 学习功法需要时间 |

### 6.2 学习时间

| 功法等级 | 天赋高 | 天赋中 | 天赋低 |
|:---|:---|:---|:---|
| **凡级** | 1个月 | 3个月 | 6个月 |
| **黄级** | 3个月 | 6个月 | 1年 |
| **玄级** | 1年 | 3年 | 5年 |
| **地级** | 5年 | 10年 | 20年 |
| **天级** | 10年 | 20年 | 50年 |
| **仙级** | 50年 | 100年 | 无法学习 |

### 6.3 功法冲突

| 冲突类型 | 说明 | 后果 |
|:---|:---|:---|
| **属性冲突** | 火系功法与水系功法冲突 | 修炼效率降低50% |
| **境界冲突** | 低境界功法与高境界功法冲突 | 无法同时修炼 |
| **流派冲突** | 不同流派的功法冲突 | 可能走火入魔 |

## 10. 归墟系统与功法

### 10.1 功法推演规则

| 规则 | 说明 |
|:---|:---|
| **推演条件** | 需要功法残篇或功法信息 |
| **推演代价** | 表面消耗寿元（每推演一个等级消耗1年寿元），实际消耗天道石算力（无穷） |
| **推演结果** | 获得完整功法或优化功法 |
| **推演限制** | 无法推演超过当前境界的功法 |

### 10.2 功法推演优势

| 优势 | 说明 |
|:---|:---|
| **无丹毒** | 推演的功法没有副作用 |
| **效率高** | 学习时间缩短50% |
| **可优化** | 可以推演优化版本 |
| **可组合** | 可以推演组合功法 |

### 10.3 功法推演限制

| 限制 | 说明 |
|:---|:---|
| **境界限制** | 无法推演超过当前境界的功法 |
| **代价限制** | 表面每推演一个等级消耗1年寿元，实际消耗天道石算力（无穷） |
| **信息限制** | 需要功法残篇或功法信息 |
| **时间限制** | 推演需要时间 |

## 11. 功法禁区和注意事项

### 11.1 功法禁区

| 禁区 | 说明 |
|:---|:---|
| **功法随意升级** | 功法升级需要资源和时间，不能随意升级 |
| **功法效果随意变化** | 功法效果固定，不能随意变化 |
| **功法无代价学习** | 学习功法需要时间和资源 |
| **功法无限叠加** | 功法有冲突，不能无限叠加 |

### 11.2 写作注意事项

```
【功法写作规则】

1. 功法等级必须与境界对应
2. 功法效果必须固定，不能随意变化
3. 学习功法必须有时间和资源成本
4. 功法冲突必须考虑
5. 主角的功法必须有来源说明
6. 归墟系统推演功法必须有代价
```
