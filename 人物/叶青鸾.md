# 叶青鸾

## 1. 基本信息

- **身份**：散修、炼丹天才
- **定位**：炼丹术顶尖、社交恐惧

## 2. 外貌

- 不修边幅
- 衣服上常有丹灰
- 头发有时乱糟糟
- 五官精致
- 清冷型

## 3. 性格

- **痴迷炼丹**：除了炼丹什么都不关心
- **社交恐惧**：不擅长和人打交道，说话直接
- **不懂人情世故**：不会看脸色，不会说场面话
- **执着**：对炼丹有近乎偏执的追求

## 4. 能力

| 维度 | 内容 |
|:---|:---|:---|
| **炼丹术** | 顶尖，远超同境界 |
| **丹方** | 记忆力惊人，见过就忘不了 |
| **境界** | 练气后期 |
| **战斗** | 很弱，基本不会打架 |

## 5. 背景

- 出身普通散修家庭
- 从小痴迷炼丹
- 炼丹天赋极高，但社交能力极差
- 在坊市边缘租了个小地方炼丹

## 6. 特点

- 说话从来不绕弯子
- 被人夸会不知所措
- 看到新丹方会眼睛发亮
- 可以为了炼丹三天不睡觉
- 对炼丹之外的事情完全不感兴趣
