# 叶青鸾

## 1. 核心标签

- **身份**：散修 → 炼丹天才 → 主角的炼丹技术负责人
- **定位**：炼丹术顶尖、社交恐惧
- **情感驱动**：知己（第一个理解她的人）
- **一句话总结**：她不需要全世界理解，只需要一个人

## 6. 情绪动机

### 6.1 核心痛点

| 维度 | 内容 |
|:---|:---|:---|
| **核心痛点** | 炼丹理论被整个宗门否定 |
| **情感需求** | 被理解、被认可 |
| **加入原因** | 主角是第一个理解她炼丹理论的人 |

### 6.2 背景故事

```
叶青鸾曾经是天机宗的炼丹天才。

她提出了一个理论：
"丹药可以无丹毒，只要控制好火候和药材配比。"

整个宗门嘲笑她：
"丹毒是炼丹的必然产物，怎么可能消除？"
"你一个练气期，懂什么炼丹？"
"别异想天开了。"

她被赶出宗门，成为散修。

她坚持自己的理论，但没有人相信她。

直到她遇到主角。

主角看了她的笔记，说：
"你的理论是对的。丹毒确实可以消除。"

那一刻，她哭了。

不是因为主角能帮她实现理论。
而是因为——
终于有人理解她了。
```

## 9. 特点

- 说话从来不绕弯子
- 对炼丹之外的事情完全不感兴趣
- 被人夸炼丹技术会脸红
- 被人夸"漂亮"会完全没反应
- 只有在炼丹时才会眼睛发亮

## 10. 与工业化主题的关系

```
叶青鸾的炼丹理论，本质上是"工业化炼丹"：

传统炼丹：
- 依赖炼丹师个人能力
- 成功率不稳定
- 丹毒无法避免

她的理论：
- 标准化流程
- 可复制
- 无丹毒

这正是主角需要的"工业化炼丹"基础。

她是主角第一次工业革命的核心技术人才。
```
