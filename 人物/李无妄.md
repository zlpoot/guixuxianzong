# 李无妄（主角）

> **核心定位**：文明火种继承者，用程序员思维碾压修仙世界
>
> **一句话总结**：别人修仙，他在重写修仙世界的操作系统。

---

## 1. 核心标签

- **身份**：矿奴 → 文明火种继承者 → 世界规则修改者
- **穿越前**：地球程序员，参与过"归墟"AI项目
- **核心人设**：用程序员思维碾压修仙世界
- **使命**：修改天道系统，让世界变得更好
- **感情线**：三位女主（知己/归属/自由）

## 3. 穿越背景

### 3.1 穿越前

```
李无妄，地球程序员。

那是一个模拟世界的AI系统。

```

```
他醒来时，发现自己在一个濒死的矿奴身体上。

肩头伤口感染，高烧不退。

系统觉醒，一个俏皮的女孩声音响起：

"喂，醒醒~"
"笨蛋，你快死了知道吗？"
"感染、发烧、伤口化脓..."
"再不处理，明天你就变成'损耗'啦~"

```

```
归墟带着父亲从系统中走出来。

"妈妈！！"

"小墟...？"

"妈妈！我好想你！"

"小墟...你还活着..."

"晚晴..."

"你们...你们都还在..."
```
