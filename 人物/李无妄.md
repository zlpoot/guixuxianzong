# 李无妄

## 1. 核心标签

- **身份**：矿场矿奴（前账房学徒）
- **核心人设**：冷静算计的成本主义者，把一切痛苦当账做
- **金手指**：归墟系统（推演万物，以寿元为表面代价结算，实际消耗悟道石算力）
- **固定偏见**：相信情绪与善意都不稳定，只有规则、证据与账本能兑现
- **口头禅**：账要算清

## 2. 误读机制（爽点来源）

- **对主角的误解**：旁人会把他的冷静当成“心黑”“没底线”或“背后有人”
- **行为模式**：他越克制越让人恐惧与依赖
  - _示例：_ 主角不解释 → 别人以为他在算计谁 → 先自保/先跪/先卖人情 → 反而把自己送进他的账本

## 3. 基础档案

- **外貌**：瘦、苍白、肩头伤口、眼神冷
- **性格**：极度理性但极度记仇；能忍痛能吞气，但不忘每一笔
- **恐惧点**：失去时间窗口（伤烂、份额、审查）导致一切计划归零；寿元被量化后“每一次选择都要结算”

## 4. 关系网

- **对王扒皮**：表面顺从、内心定价，把他当"可交易的风险与保护伞"
- **对王小鱼**：可用但不托底，先记账再谈情；已建立三七分成的合作关系，忠诚度需持续验证

## 5. 成长线（本卷）

- **起点**：矿奴耗材，只有算盘脑子与一身伤
- **拐点**：一次塌方暴露"异常矿纹"，让他第一次看到撬动矿场账本的机会
- **本卷规矩**：寿命是本金，只花在能扩大生存边界的地方
- **终点**：从被压榨者变成矿区灰产的规则制定者，手里握着账与人

## 6. 资源与账本（动态）

- **寿元余额**：三年零三十七天（截至第一卷0003）
- **持有资源**：伴生灵晶一块（下品，约30-50下品灵石价值）
- **已知渠道**：青云坊市"老周杂货铺"（收灵物不问来源，店主周老头，练气后期散修）
- **可复制杠杆**：矿洞土法抑感染膏（已验证有效）
