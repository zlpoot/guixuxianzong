# 丹鼎阁阁主

## 1. 核心标签

- **身份**：丹鼎阁第十五任阁主、化神期强者
- **核心人设**：表面医者仁心，实则垄断暴利的商人
- **固定偏见**：认为"丹药垄断"是丹鼎阁存在的根基，任何改革都是威胁
- **口头禅**：丹药救人，但也要养活丹鼎阁

## 2. 基础档案

- **姓名**：药无尘
- **年龄**：1800岁
- **境界**：化神初期
- **外貌**：儒雅温和、常穿药香道袍、面带微笑
- **性格**：表面温和、实则冷酷、利益至上
- **恐惧点**：丹药垄断被打破、无丹毒丹方流传出去

## 3. 能力与资源

| 维度 | 内容 |
|:---|:---|
| **境界** | 化神初期（寿元2000-3000年） |
| **功法** | 丹心诀（天级功法） |
| **法器** | 天丹炉（天级法器，阁主信物） |
| **资源** | 控制丹药市场，垄断丹方 |

## 4. 丹药垄断策略

| 策略 | 说明 |
|:---|:---|
| **控制丹方** | 所有高级丹方都被丹鼎阁垄断 |
| **控制药材** | 控制主要药材产地 |
| **控制炼丹师** | 所有高级炼丹师都被丹鼎阁招揽 |
| **打压竞争者** | 任何试图炼制丹药的人都会被打压 |

## 5. 与主角的关系

| 阶段 | 关系 | 说明 |
|:---|:---|:---|
| **第一卷** | 未知 | 不知道主角存在 |

| **第三卷** | 敌对 | 主角打破丹药垄断，成为敌人 |
| **第四卷** | 失败 | 被主角击败，丹鼎阁垄断被打破 |
