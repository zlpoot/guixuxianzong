# 钱多多

## 1. 基本信息

- **身份**：散修、商人
- **定位**：财迷、搞笑担当、主角的商业主力

## 2. 外貌

- 圆脸
- 小眼睛
- 笑起来眼睛眯成一条缝
- 看起来憨厚

## 3. 性格

- **见钱眼开**：看到钱就走不动路
- **精于算计**：能把一块灵石掰成两半花
- **讲义气**：朋友有难绝不袖手旁观
- **乐观**：天塌下来当被子盖

## 4. 能力

| 维度 | 内容 |
|:---|:---|:---|
| **商业能力** | 优秀，对市场敏感 |
| **境界** | 练气中期 |
| **战斗** | 弱，遇到危险就跑 |
| **人脉** | 三教九流都认识一点 |

## 5. 背景

- 出身贫寒散修家庭
- 从小就知道钱的重要性
- 靠倒买倒卖积累了一些资源
- 在坊市混迹多年

## 6. 特点

- 平时抠门，但朋友需要钱时比谁都大方
- 看到好买卖眼睛会发光
- 嘴上说着"亏了亏了"，实际赚翻了
- 关键时刻靠得住
- 搞笑担当，总能在紧张时说些让人哭笑不得的话
