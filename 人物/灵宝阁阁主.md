# 灵宝阁阁主

## 1. 核心标签

- **身份**：灵宝阁第十五任阁主、化神期强者
- **核心人设**：精明的商人，把法器当商品，把修士当客户
- **固定偏见**：认为"法器垄断"是灵宝阁存在的根基，任何改革都是威胁
- **口头禅**：好法器，好价格

## 2. 基础档案

- **姓名**：宝无缺
- **年龄**：1500岁
- **境界**：化神初期
- **外貌**：富态、常穿锦衣、面带商人笑容
- **性格**：精明、务实、利益至上但讲究信誉
- **恐惧点**：法器垄断被打破、灵铁矿脉被抢夺

## 3. 能力与资源

| 维度 | 内容 |
|:---|:---|
| **境界** | 化神初期（寿命2000-3000年） |
| **功法** | 炼器诀（天级功法） |
| **法器** | 天工锤（天级法器，阁主信物） |
| **资源** | 控制灵铁矿脉，垄断法器市场 |

## 4. 法器垄断策略

| 策略 | 说明 |
|:---|:---|
| **控制矿脉** | 控制主要灵铁矿脉 |
| **控制炼器师** | 所有高级炼器师都被灵宝阁招揽 |
| **控制材料** | 控制主要炼器材料 |
| **打压竞争者** | 任何试图炼制法器的人都会被打压 |

## 5. 与主角的关系

| 阶段 | 关系 | 说明 |
|:---|:---|:---|
| **第一卷** | 未知 | 不知道主角存在 |
| **第二卷** | 警惕 | 发现主角的法器设计威胁灵宝阁利益 |
| **第三卷** | 敌对 | 主角打破法器垄断，成为敌人 |
| **第四卷** | 妥协 | 看到主角的势力，选择合作 |

## 6. 商业哲学

| 维度 | 说明 |
|:---|:---|
| **信誉至上** | 灵宝阁的法器质量有保证 |
| **明码标价** | 价格虽高但透明 |
| **客户至上** | 对大客户提供定制服务 |
| **利益优先** | 在利益面前，没有永远的敌人 |

## 7. 秘密

| 秘密 | 说明 |
|:---|:---|:---|
| **知道矿脉争夺战真相** | 灵宝阁的矿脉是通过战争抢来的 |
| **知道法器垄断的代价** | 很多散修因为买不起法器而死 |
| **暗中支持改革** | 如果改革能带来更多利润，他不介意 |

"好法器，好价格。灵宝阁从不骗人。"

"法器是修士的命，我们卖的是命。"

"如果改革能带来更多利润，我为什么不支持？"
