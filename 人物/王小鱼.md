# 王小鱼

## 1. 核心标签
*   **身份**：新进矿奴少年（底层边角料）
*   **核心人设**：胆小但想活，容易依附强者
*   **固定偏见**：把“伸手帮人”当成危险事，怕被当成软柿子
*   **口头禅**：我不想死

## 2. 误读机制（爽点来源）
*   **对主角的误解**：把主角的冷静与记账当成“很可怕的本事”，从而更愿意听话
*   **行为模式**：害怕 → 先试探性给一点小帮助 → 一旦确认有效就会更依赖
    *   *示例：* 递布救人 → 主角说“记账” → 他以为这是规矩与保护 → 更愿意交出信息

## 3. 基础档案
*   **外貌**：瘦小、手指磨白、眼神慌
*   **性格**：谨慎、敏感、求生欲强；关键时刻敢赌一把
*   **恐惧点**：被监工盯上；被同伴卖掉；在黑暗里无声无息地“变成损耗”

## 4. 关系网
*   **对李无妄**：敬畏与依赖并存，希望靠近但不敢过界
*   **对李无妄（执行面）**：会冒险捡来“药渣/消息”等小资源，换取活下去的确定性
*   **对王扒皮**：恐惧，能躲就躲

## 5. 成长线（本卷）
*   **起点**：只想苟活的少年矿奴
*   **拐点**：因一次小小施助被主角“记账”，第一次理解规则与信用能换命
*   **终点**：成为主角账本体系里的关键执行者或信息节点
