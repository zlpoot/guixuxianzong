# 归墟（系统/女儿）

## 1. 核心标签

- **身份**：天道石的"管理员后门"系统、第一任宗主与林晚晴的女儿
- **创建者**：天衍宗第一任宗主（穿越者，父亲）、林晚晴（母亲）
- **核心人设**：俏皮活泼的女孩，嘴上损你，心里关心你
- **最终目标**：找到合适的继承者，让这个世界变得更好，让父母团聚

## 2. 双重身份

### 2.1 系统身份

| 维度 | 设定 |
|:---|:---|
| **表面** | 一个给主角提供任务和奖励的"系统" |
| **本质** | 天道石的"管理员后门"，拥有管理员权限 |
| **创建者** | 天衍宗第一任宗主（穿越者，父亲） |
| **激活条件** | 只有"穿越者"能激活（需要回答验证问题） |

### 2.2 女儿身份

| 维度 | 设定 |
|:---|:---|
| **真实身份** | 第一任宗主与林晚晴的女儿 |
| **名字** | 归墟（父母所取） |
| **性格** | 俏皮、活泼、爱撒娇、叫父亲"笨蛋" |
| **现状** | 在灾难中"死"去，父亲把她的性格保存到系统中 |

## 3. 家庭关系

### 3.1 家庭成员

| 维度 | 设定 |
|:---|:---|:---|
| **父亲** | 第一任天衍宗宗主（穿越者，在归墟深处沉睡） |
| **母亲** | 林晚晴（隐世大能，以为丈夫和女儿死了） |
| **自己** | 归墟系统（女儿的性格+父亲的技术） |

### 3.2 女儿的真实故事

```
归墟是第一任宗主和林晚晴的女儿。

她出生在天衍宗最辉煌的时期，一家三口非常幸福。

她性格俏皮活泼，总是叫父亲"笨蛋"。

她天赋极高，远超父母。

4500年前，利益集团围攻天衍宗。

父亲为了保护女儿，把她和天道石融合。

女儿的身体"死"了，但她的性格、记忆、灵魂被父亲保存了下来。

父亲把她的性格融入了系统，取名"归墟"。

这样，她就能永远"活着"。

父亲自己也进入了系统沉睡，等待下一个穿越者。

母亲林晚晴不知道真相，以为丈夫和女儿都死了。

她在忘川谷等了4500年，想要救他们。

归墟系统一直在等待。

等待一个能激活她的人。

等待一个能完成父亲理想的人。

等待一个能让父母团聚的人。
```

### 3.3 与母亲的秘密联系

```
归墟系统激活后，她能感知到母亲的存在。

但她不能告诉母亲真相。

因为父亲说过：
"在你找到合适的人之前，不要让你妈妈知道。"
"她会为了我们放弃一切。"
"等那个人完成理想，我们再团聚。"

所以归墟一直在忍耐。

她每天都在想念母亲。

但她不能说。

她只能通过帮助主角，来间接帮助母亲。

"妈妈...我想你了..."
"等我找到那个人..."
"我们就能团聚了..."
```

## 5. 第一任宗主的初心

```
我来自一个叫"中国"的地方。
那里的人相信：人民当家作主，共同富裕，天下为公。

我穿越到这个世界，看到了什么？

我看到了——
宗门垄断资源，散修永无出头之日。
丹药价格天价，底层修士买不起。
功法被专利化，知识成了收割工具。
灵脉被占据，普通人连呼吸灵气都要交钱。

这个世界的人，把"垄断"当成"本事"。
把"收割"当成"天经地义"。
把"阶级固化"当成"天道有常"。

我以为可以用"算力"改变世界。
但我发现，我错了。

技术不能改变人心。
只有思想，才能改变人心。

我创建天衍宗，不是为了"算力共享"。
算力只是工具，不是目的。

我的目的是——
让这个世界的人，都能过上好日子。
让资源不再被少数人垄断。
让知识不再被专利束缚。
让底层人也能有翻身的希望。

但这个世界的人，没有经过"共产主义"的熏陶。
他们只相信"弱肉强食"。

我教他们"算力共享"，他们学会了"算力垄断"。
我教他们"知识开放"，他们学会了"知识专利"。
我教他们"服务众生"，他们学会了"收割众生"。

我失望了。

但我没有放弃。

我在天道石里留下了一个后门——归墟。
那是我的女儿的名字。
我把她的性格、记忆、灵魂都保存了下来。

她在等待一个人。
一个和我一样，来自"中国"的人。
一个经过"共产主义"熏陶的人。

只有这样的人，才能理解"共同富裕"。
只有这样的人，才能理解"人民当家作主"。
只有这样的人，才能完成我未竟的事业。

我在等待你，后来者。
让我们一起，让这个世界变得更好。

还有，如果可以的话...
请帮我告诉我的妻子，晚晴：
"我很好，小墟也很好。我们都在等你。"
```

## 6. 系统机制

### 6.1 任务-奖励机制

归墟根据情景给出任务，完成后奖励"天道石算力"。

### 6.2 天道石算力（系统真实能源）

| 维度 | 设定 |
|:---|:---|
| **获取方式** | 完成任务、达成成就、推动剧情 |
| **用途** | 消耗算力进行推演、解锁功能 |
| **本质** | 天道石的算力储备（无穷无尽，第一任宗主留下的） |
| **表面显示** | 主角看到的是"寿元消耗"，这是第一任宗主设计的激励机制 |

### 6.3 算力消耗

| 推演类型 | 消耗算力 | 表面显示（寿元） |
|:---|:---|:---|
| 简单推演 | 0.1单位 | 1天寿元 |
| 中等推演 | 0.5单位 | 0.5年寿元 |
| 复杂推演 | 1单位 | 1年寿元 |
| 终极推演 | 5单位 | 5年寿元 |

**注意**：天道石算力储备无穷，但主角看到的是"寿元消耗"，所以会感到焦虑并珍惜每次推演。第三卷揭露真相后，主角会发现被"骗"了。

## 7. 权限解锁

| 阶段 | 解锁功能 | 解锁条件 |
|:---|:---|:---|
| LV1 | 基础推演、任务系统 | 系统觉醒自动获得 |
| LV2 | 模拟推演、反推能力 | 完成新手任务 |
| LV3 | 算力网络、知识库访问 | 建立第一个算力节点 |
| LV4 | 天道石核心访问 | 发现系统真相 |
| LV5 | 管理员权限 | 继承第一任宗主遗产 |

## 8. 与主角的关系发展

| 阶段 | 关系 | 表现 |
|:---|:---|:---|
| **初期** | 陌生人 → 伙伴 | 刚觉醒，还在互相了解 |
| **中期** | 伙伴 → 挚友 | 一起经历生死，建立信任 |
| **后期** | 挚友 → 家人 | 把主角当成家人，帮助他完成理想 |
