# 第一任天衍宗宗主

## 1. 核心标签

- **身份**：天衍宗创始人、穿越者、归墟系统创造者
- **核心人设**：理想主义的改革者，试图用现代知识改变修仙世界
- **固定偏见**：相信"知识共享"能让世界更美好
- **口头禅**：算力属于所有人

## 2. 历史定位

- **穿越时间**：5000年前
- **穿越前身份**：21世纪AI研究员
- **穿越后成就**：建立天衍宗、建造天道石、创造归墟系统
- **最终结局**：4500年前进入归墟系统沉睡

## 3. 基础档案

- **外貌**：清瘦儒雅、目光深邃、常穿白色道袍
- **性格**：理想主义、执着、善良但现实
- **恐惧点**：自己的理想被后人扭曲、妻子和女儿受苦
- **道侣**：林晚晴（隐世大能）
- **女儿**：归墟（系统人格原型，在灾难中"死"去）

## 4. 感情线

### 4.1 与林晚晴的故事

| 阶段 | 时间 | 事件 |
|:---|:---|:---|
| **初遇** | 5000年前 | 刚穿越被妖兽追杀，被林晚晴救下 |
| **相恋** | 4980年前 | 遗迹探险中互诉心意 |
| **成婚** | 4950年前 | 在天衍宗建立前夕结为道侣 |
| **女儿出生** | 4900年前 | 女儿归墟出生，一家三口幸福 |
| **灾难** | 4500年前 | 利益集团围攻，女儿"死"去，他进入系统沉睡 |

### 4.2 女儿归墟

| 维度 | 说明 |
|:---|:---|:---|
| **名字** | 归墟（林晚晴所取，意为"万物之所归"） |
| **性格** | 俏皮、活泼、爱撒娇、叫父亲"笨蛋" |
| **天赋** | 极高，远超父母 |
| **结局** | 在灾难中"死"去，父亲把她的性格保存到系统中 |

### 4.3 那场灾难

```
【场景：4500年前，利益集团围攻天衍宗】

敌人太多，天衍宗即将覆灭。

第一任宗主做出了决定：

他把女儿归墟和天道石融合，保存了她的性格、记忆、灵魂。

女儿的身体"死"了，但她的精神永远"活着"。

他自己也进入了系统沉睡，等待下一个穿越者。

他对妻子林晚晴说：

"晚晴，对不起。"

"我必须保护小墟。"

"她太小了，她不能死。"

"我会把她的性格保存下来。"

"等我找到合适的人，我们就能团聚。"

林晚晴不知道真相。

她以为丈夫和女儿都死了。

她在废墟中找到了丈夫的道袍和女儿的发簪。

她抱着这两样东西，坐了整整一年。

然后她站起来，眼中不再有泪，只有坚定：

"他们没有死。"

"我一定能找到救他们的方法。"

"等我。"
```

### 4.4 对妻子的愧疚

```
第一任宗主最大的愧疚，就是让妻子以为他们死了。

他知道妻子会多么痛苦。

但他没有选择。

如果告诉妻子真相，她会为了他们放弃一切。

她不会安心修炼，不会提升实力。

她只会四处寻找，最终被敌人发现。

所以他选择了隐瞒。

"晚晴，对不起。"

"等你足够强大，我们就能团聚。"

"在那之前，请原谅我的自私。"
```
