# 苏玲珑

## 1. 基本信息

- **身份**：神机宗宗主孙女、神机宗核心传承者
- **定位**：傀儡术天才

## 2. 外貌

- 身材瘦小
- 手指修长（适合做傀儡）
- 眼神冷
- 冷艳型

## 3. 性格

- **沉默寡言**：不爱说话，能用动作解决就不用语言
- **只对傀儡有兴趣**：提到傀儡才会眼睛发亮
- **对人有戒心**：不轻易信任任何人
- **执着**：认定的事情会坚持到底

## 4. 能力

| 维度 | 内容 |
|:---|:---|
| **傀儡术** | 顶尖，继承了神机宗核心传承 |
| **机关术** | 精通 |
| **战斗** | 通过傀儡战斗，本体战力一般 |
| **境界** | 练气中期 |

## 5. 背景

- 神机宗宗主孙女
- 宗门被覆灭时侥幸逃脱
- 身上带着神机宗核心传承
- 被追杀中

## 6. 特点

- 身上总带着小型傀儡
- 说话简短，能说三个字绝不说五个字
- 对傀儡比对人亲近
- 记仇，但不会主动报复，只会默默记着
