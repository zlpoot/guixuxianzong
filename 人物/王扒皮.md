# 王扒皮

## 1. 核心标签
*   **身份**：黑石矿场监工（底层管理者，靠鞭子吃饭）
*   **核心人设**：极度贪婪但极度多疑，习惯用暴力维护秩序
*   **固定偏见**：认为所有人都在骗他、坑他，只有恐惧能让人听话
*   **口头禅**：矿场不缺人

## 2. 误读机制（爽点来源）
*   **对主角的误解**：把主角的冷静当成“背后有人”或“在做大事”，从而先压后拉
*   **行为模式**：先用暴力试探底线，再用利益做笼子
    *   *示例：* 发现异常苗头 → 先抽一鞭看你会不会崩 → 不崩就想把你收编 → 收编不了就想毁掉

## 3. 基础档案
*   **外貌**：肥壮、铁牌叮当、鞭子不离手、眼神油滑
*   **性格**：凶狠、现实、翻脸快；嗅觉灵敏，见利就扑
*   **恐惧点**：上面查账与失去职位；任何会让矿场“账不好看”的东西

## 4. 关系网
*   **对李无妄**：先把他当耗材，后把他当能生钱的工具与潜在威胁
*   **对矿奴群体**：纯压榨与恐吓的管理对象，不当人看

## 5. 成长线（本卷）
*   **起点**：靠鞭子稳住矿区，吃矿奴与矿场两头的油水
*   **拐点**：发现矿区出现“能赚钱也能惹祸”的新东西，被迫从单纯暴力转向控制与交易
*   **终点**：要么被更高层清洗，要么沦为主角制度里的第一枚棋子
