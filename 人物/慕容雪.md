# 慕容雪

## 1. 基本信息

- **身份**：灵宝阁东海区域最高管事的独女
- **定位**：傲娇大小姐

## 2. 外貌

- 打扮精致
- 气场强
- 一眼就 notice
- 明艳型

## 3. 性格

- **傲娇**：嘴硬心软，明明关心却说不出口
- **嚣张但有底线**：不会欺负弱小，但也不会被人欺负
- **聪明**：看似娇生惯养，实际很有商业头脑
- **不服输**：被比下去会想办法赢回来

## 4. 能力

| 维度 | 内容 |
|:---|:---|:---|
| **商业能力** | 优秀，从小耳濡目染 |
| **境界** | 练气后期 |
| **战斗** | 中等，主要靠法器 |
| **人脉** | 灵宝阁的背景让她有很多资源 |

## 5. 背景

- 灵宝阁东海区域最高管事的独女
- 从小被娇养，但不是温室花朵
- 对商业有兴趣，想证明自己
- 偶尔会去各地"考察"

## 6. 特点

- 嘴上说着"我才不在乎"，实际很在意
- 被人夸会傲娇地说"那当然"
- 对感兴趣的人会偷偷关注
- 有自己的骄傲和底线
- 不会承认自己错了，但会用行动弥补
