# 萧逸尘

## 1. 基本信息

- **身份**：散修、商业天才
- **定位**：亦敌亦友

## 2. 外貌

- 长相斯文
- 穿着讲究但不张扬
- 眼神温和但藏着精明
- 气质儒雅

## 3. 性格

- **精明**：商业头脑极强，算计精准
- **有野心**：不甘心只做散修，想建立自己的势力
- **讲规矩**：竞争归竞争，不玩阴的
- **识人**：看人很准，知道谁值得合作

## 4. 能力

| 维度 | 内容 |
|:---|:---|:---|
| **商业能力** | 顶尖，散修起家能做到这个程度 |
| **境界** | 筑基初期 |
| **战斗** | 中等，主要靠脑子 |
| **人脉** | 散修圈子里人脉很广 |

## 5. 背景

- 出身普通散修家庭
- 靠商业头脑一步步积累资源
- 从练气到筑基都是自己赚资源突破的
- 在坊市有自己的生意

## 6. 特点

- 笑着说话，但每句话都有目的
- 竞争时全力以赴，但不会下黑手
- 认可的人会真心合作
- 有自己的商业原则
- 看起来好说话，实际很难被忽悠
