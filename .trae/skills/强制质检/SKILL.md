# 强制质检

## 目标

作为“一条龙出章”流程的守门员，或者用户单独调用的“找茬工具”，对草稿进行**极度严格**的自动化扫描，确保没有低级逻辑错误。

## 何时调用

- **自动调用**：在 `一条龙出章` 的“强制质检与修订”环节被调用。
- **手动调用**：用户说“强制检查这章”、“扫描一下有没有漏洞”、“看看战力崩没崩”。

## 必读上下文

1. `草稿/`（待检查的章节）
2. `设定/`（世界规则、能力边界、科技水平、组织权限等）
3. `人物/`（角色动机、底线、口吻、认知边界）
4. 若存在：`笔记/项目圣经.md`、`笔记/事件台账.md`、`笔记/术语表.md`、`笔记/文风基准.md`

## 检查清单

请逐条扫描以下风险点：

### 1. 设定边界穿帮（最为致命）

- **规则**：任何能力、科技、魔法、组织权限、道具等级不得越过设定边界；若边界未写明，优先用模糊写法避免硬断言。
- **常见错误**：
  - 角色突然获得不可能的能力或资源（前文没有铺垫）。
  - 关键物件等级与稀有度失衡（随手一捡就是“终极神器”）。
  - 场景里的技术细节明显不符合时代与世界规则。

### 2. 人设走样扫描（角色一致性）

- **所有角色**：
  - 是否违背人物卡的动机、底线、恐惧点？
  - 是否出现“口吻漂移”（同一人前后说话风格变化过大）？
  - 是否出现“认知越界”（突然知道其不该知道的秘密）？
  - 是否出现“强行降智或强行聪明”（为了剧情硬拗）？

### 3. 逻辑断层扫描

- **前后矛盾**：上一段说“重伤垂死”，下一段“活蹦乱跳”且没有解释。
- **数量/单位错误**：如“三个人”变成了“四个人”。
- **时间线混乱**：早上发生的事写成了晚上。
- **称呼与名词漂移**：同一人名、地名、组织名出现多种写法。

## 执行动作

### 模式一：自动修正

**适用场景**：在“一条龙出章”流程中，或用户明确要求“直接改”。

1. 发现问题后，直接对草稿文件做最小改动修复。
2. 修改原则：**降级处理**（把夸张写法收回到设定边界内）、**模糊处理**（不确定的设定改成更安全的表达）、**补丁解释**（补一句心理活动或必要的过渡）。
3. 在对话中输出报告：“已自动修正若干处问题：{列出修改点}”。

### 模式二：只出报告

**适用场景**：用户只想看问题，不希望自动改文。

1. 输出一份详细的《质检报告》，列出所有可疑点。
2. 等待用户指令再修改。

## 输出示例

```
### 强制质检报告

- ✅ **设定边界**：通过（无越界能力与越级物件）。
- ⚠️ **人设警告**：某处角色突然转向，动机不足，建议补一句铺垫或改为更符合人物卡的反应。
- ❌ **逻辑错误**：某处数量前后不一致。
- **修正操作**：已自动修复逻辑错误；人设警告请人工确认后再改。
```
