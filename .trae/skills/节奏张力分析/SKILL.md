# 节奏张力分析

## 目标

对指定章节做"读者体验体检"：哪里在拖、哪里信息不够、哪里爽点没打中、章末钩子是否有拉力，并给出可直接改的建议清单。

## 何时调用

- 用户说"这章太水""节奏慢""不够爽""留不住人"
- 用户准备发章前做最后一次节奏体检
- 用户想把多章统一成同一套节奏标尺

## 输入

- 章节文件路径或正文片段
- 若未提供：默认定位 `草稿/` 的最新一章

## 必读上下文

- `大纲.md`
- 若存在：`笔记/文风基准.md`、`笔记/项目圣经.md`

## 输出格式

按以下结构输出，不要长篇解释：

1. 节奏分段：把正文按"铺垫、冲突、转折、回响、钩子"切开，并给每段大致字数占比
2. 问题清单：不超过十条，每条都要指出"问题位置"与"读者感受"
3. 可执行改法：对应每条问题给出一条可直接替换的句子或段落方向
4. 钩子评分：给出一条更强的最后一句备选

## 规则

- 不改既定大事件走向，优先通过删冗、前置冲突、加强张力来提速提爽
- 任何改动不得导致"主角人设崩塌"（理性算计型人物不得突然冲动、不计成本）或"配角降智"
