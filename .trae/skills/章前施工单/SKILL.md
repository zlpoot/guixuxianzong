# 章前施工单

## 目标

在不直接写正文的前提下，把已有大纲、设定与上一章结尾，整理成“本章可执行的写作施工单”，用于驱动后续的正文生成。
核心逻辑：确保每一章都有明确的“本章目标”与“核心阻碍”，并产出可落地的镜头节奏与钩子。

## 何时调用

- 用户说“要写下一章”“开新章”“先出本章计划”
- 用户要求“这一章怎么写更爽、更稳”
- 用户强调需要爆点、节奏、章末钩子或关键行动链约束

## 必读上下文（尽量从仓库读取）

1. `大纲.md`
2. `章纲/` 下本章对应的章纲文件（若存在）
3. `正文/` 下上一章的结尾（用于接钩子）
4. `设定/`、`人物/`、`笔记/` 中与本章相关的条目（若存在）

## 输出格式（表格 + 补充说明）

请直接输出以下表格，不要废话：

### 1. 核心施工表

| 检查项                      | 内容                                                       | 备注                                                         |
| :-------------------------- | :--------------------------------------------------------- | :----------------------------------------------------------- |
| **本章目标**                | （必填）例如：修好门锁、拿到证据、完成交易。               | 必须清晰、可执行。                                           |
| **核心阻碍（对立面）**      | （必填）例如：对手设下阻拦、规则限制、灾害逼近、关键误会。 | 必须具体、能制造压力。                                       |
| **关键动作（策略）**        | （必填）例如：设局试探、谈判交换、潜入取证、紧急撤离。     | 必须能推动局势变化。                                         |
| **结果与回响（兑现/代价）** | （必填）例如：拿到线索但付出代价、赢了却埋下更大误会。     | 让读者感到“有变化”。                                         |
| **资源变化**                | （必填）例如：线索加一、现金减一、关系破裂或缓和。         | 必须有得失（资源、关系、地位、伤势、证据等）。               |
| **章末钩子**                | （必填）例如：新的证据指向更大对手；有人来追查。           | 必须引出下一章驱动力（追查、求助、灾变、任务、榜单等之一）。 |

### 2. 节奏与细节填充

- **单章节奏规划**：
  - **铺垫（20%）**：{当下处境与本章目标}
  - **冲突（30%）**：{外界找茬与危机逼近}
  - **推进（30%）**：{关键动作推动局势变化}
  - **回响（10%）**：{结果带来的反应与余波}
  - **钩子（10%）**：{下章悬念}
- **关键台词/口头禅**：{列出主角本章要说的 1-2 句辨识度台词}
- **风险提示**：{是否有设定越界？动机不成立？认知越界？称呼漂移？}

## 约束

- **角色不越界**：认知、动机、能力边界必须与人物卡一致。
- **设定不越界**：能力、科技、组织权限与道具等级必须与设定一致。
- **钩子必留**：最后一句必须引出下一章驱动力。
