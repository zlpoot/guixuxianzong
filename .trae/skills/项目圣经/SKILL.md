# 项目圣经

## 目标

把分散在大纲、设定、人物卡、章节与正文里的信息，整理成一份“全项目唯一口径”的圣经文件，供后续写作、质检、改写统一参照。

## 何时调用

- 用户说“整理设定”“做项目圣经”“把现有内容收拢成唯一口径”
- 用户说“总觉得要吃书”“我怕前后不一致”
- 用户准备开新卷、加入新势力、引入关键规则之前

## 必读上下文（尽量从仓库读取）

- `大纲.md`
- `设定/`
- `人物/`
- `章纲/`
- `正文/` 与 `草稿/` 中的最新章节（用于提取已发生事件）
- `笔记/` 下现有笔记（若存在则增量更新）

## 产物与落盘

必须写入或更新以下文件（若不存在则创建）：

- `笔记/项目圣经.md`
- `笔记/事件台账.md`
- `笔记/术语表.md`

对话中只输出：更新摘要（不超过十条）+ 三个文件路径，不要输出整份圣经全文。

## 写入模板（项目圣经）

```
# 项目圣经

## 一、题材与基调
- 题材：{一句话}
- 基调：{轻松/压抑/热血/黑色幽默等}
- 核心爽点：{反差爽点一句话}
- 禁区：{绝对不能写的内容}

## 二、世界规则（只写可执行规则）
- 修炼与战力：{上限、分层、早期禁区}
- 关键设定边界：{能与不能}
- 资源与代价：{获得什么要付出什么}

## 三、人物总表（只列关键人物）
- 主角：{一句话人设}+{绝对不变的底线}+{常用口头禅}
- 核心配角：{按阵营列出}

## 四、势力与地理
- 势力：{名称、目标、与主角关系}
- 地点：{常驻地点、常用场景标签}

## 五、时间线与已发生事件
- 当前进度：{到第几章/哪一卷}
- 已发生事件清单：{按时间顺序列 10-30 条}

## 六、伏笔与回收总表
- 伏笔清单：{伏笔名、埋点、预期回收、当前状态}

## 七、文风与叙事约束（与文风基准保持一致）
- 视角：{固定}
- 叙述习惯：{句长、口语度、吐槽度}
- 信息投放：{每段要推进什么}
```

## 写入模板（事件台账）

```
# 事件台账

| 序号 | 事件 | 发生章节 | 影响人物 | 对后续的硬约束 |
| :--- | :--- | :--- | :--- | :--- |
| 1 | {事件一句话} | {卷/章} | {人物} | {不能被推翻的后果} |
```

## 写入模板（术语表）

```
# 术语表

| 术语 | 统一写法 | 别名 | 首次出现 | 说明 |
| :--- | :--- | :--- | :--- | :--- |
| {名词} | {统一写法} | {同物异名} | {卷/章} | {一句话解释} |
```
