# 创建章纲

## 目标

基于仓库内`大纲.md`与设定资料，为指定范围的章节生成“可直接写正文”的章纲，并把章纲写入仓库中对应的文件夹。
风格核心：以 `笔记/文风基准.md` 与目标读者为准，确保章纲可直接驱动正文生成。

## 何时调用

- 用户要求“出章纲/拆章/把前 N 章拆成章纲/给第 X 章章纲”
- 用户强调“章纲需要落盘/放到文件夹里”

## 必读上下文

1. `大纲.md`（必须严格遵循其中的“章前施工单”逻辑）
2. `笔记/` 下的伏笔与时间线（如果存在）

## 落盘规则

### 目录规则

- 基础目录：`章纲/`
- 卷目录：`章纲/<卷名>/`
  - 卷名请参考大纲；若大纲未分卷，则统一写入 `章纲/单卷/`

### 文件命名

- `{三位数字}.{章名}.md`（如 `001.章节名.md`）

## 章纲模板（表格版）

每章必须包含以下内容，直接写入文件：

```
# {章节序号} {章节名}

## 1. 章前施工单（核心）

| 检查项 | 内容 |
| :--- | :--- |
| **本章生活目标** | {庸俗日常目标，如：给白菜浇水} |
| **外界阻碍（对立面）** | {对手、规则、环境或内心阻碍，如：执法检查、组织追捕、灾害爆发、关键误会} |
| **行动与策略（关键动作）** | {主角本章采取的关键动作与策略，如：设局、谈判、潜入、撤离、救援} |
| **结果与反应（爽点/代价）** | {本章兑现点：胜利/失败/反转/代价/误会扩散/关系变化} |
| **资源变化** | {资源、地位、关系、线索、伤势等变化} |
| **章末钩子** | {下章驱动力：追查/求助/灾变/任务/榜单/误会升级等之一} |

## 2. 剧情细纲（镜头语言）

1.  **镜头一（铺垫）：** 主角出场，展示生活烦恼（字数占比 20%）。
    *   *细节：* {具体描写方向}
2.  **镜头二（冲突）：** 阻碍逼近，明确压力与对立面手段（字数占比 30%）。
    *   *细节：* {具体描写方向}
3.  **镜头三（转折）：** 关键行动带来局势变化（字数占比 30%）。
    *   *细节：* {具体描写方向}
4.  **镜头四（回响）：** 结果带来的反应与余波（字数占比 10%）。
    *   *细节：* {具体描写方向}
5.  **镜头五（收束）：** 资源结算，抛出钩子（字数占比 10%）。
    *   *细节：* {具体描写方向}

## 3. 信息与伏笔
*   **新增信息**：{本章引入的新设定/人物}
*   **伏笔埋藏**：{本章留下的坑}
*   **伏笔回收**：{本章填上的坑}
```

## 多章生成策略

如果是生成多章（如“前10章”）：

1.  先规划每章的“本章目标”和“核心阻碍”，确保不重复且有递进。
2.  每若干章安排一次“阶段性高潮”（重大转折、关键收获、关系洗牌或信息揭示）。
3.  逐章生成文件，并在对话中列出清单。
