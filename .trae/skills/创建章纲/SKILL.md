# 创建章纲

## 目标

根据卷纲和当前进度，生成单章章纲，确保章节目标明确、节奏合理、设定连贯。

## 何时调用

- 用户说"生成章纲"、"创建本章章纲"、"帮我规划这一章"
- 用户要开写新章节
- 用户需要章纲模板

## 输入

- 卷纲文件路径（可选）
- 章节编号（可选）
- 若未提供：从 `大纲/` 里定位最新卷纲，从 `草稿/` 里定位最新章节

## 必读上下文（尽量从仓库读取）

1. `大纲/`（卷纲、整体大纲）
2. `设定/`（世界规则、能力边界，特别注意`设定/主角能力边界.md`）
3. `人物/`（涉及角色的角色卡）
4. `笔记/`（时间线、事件台账、伏笔追踪）
5. 若存在：`笔记/项目圣经.md`、`笔记/术语表.md`

## 章纲模板

```markdown
# 第X卷 第XXX章 章节名称

## 基本信息

- **章节编号**：第X卷第XXX章
- **字数目标**：2000-3000字
- **核心事件**：[一句话概括本章核心事件]
- **爽点/钩子**：[本章的爽点或钩子]

## 前情提要

- **上一章结尾**：[上一章的结尾状态]
- **当前时间点**：[本章开始的时间点]
- **主角状态**：[主角当前的境界、资源、心理状态]

## 本章目标

1. [目标一]
2. [目标二]
3. [目标三]

## 场景分解

### 场景一：[场景名称]
- **时间**：[时间点]
- **地点**：[地点]
- **人物**：[出场人物]
- **核心事件**：[场景核心事件]
- **冲突/转折**：[场景冲突或转折]
- **字数**：[预估字数]

### 场景二：[场景名称]
- **时间**：[时间点]
- **地点**：[地点]
- **人物**：[出场人物]
- **核心事件**：[场景核心事件]
- **冲突/转折**：[场景冲突或转折]
- **字数**：[预估字数]

## 设定检查

### 归墟系统检查（若本章涉及推演）
- **推演目的**：[推演目的]
- **推演代价**：[寿元消耗]
- **推演结果**：[推演结果]
- **执行风险**：[执行风险]

### 商业逻辑检查（若本章涉及交易）
- **交易内容**：[交易内容]
- **成本**：[成本]
- **收益**：[收益]

## 伏笔埋设/回收

- **埋设伏笔**：[本章埋设的伏笔]
- **回收伏笔**：[本章回收的伏笔]

## 结尾钩子

- **结尾状态**：[本章结尾状态]
- **下一章预告**：[下一章的预告]
```

## 检查清单

### 1. 归墟系统检查（本项目特有，最高优先级）

- **推演必要性**：本章是否需要推演？推演是否必要？
- **推演代价**：若涉及推演，是否明确"寿元"代价？数值是否合理？
- **推演边界**：推演结果是否符合"只给路径、不包成功"的设定？
- **境界限制**：推演结果是否超过主角当前境界？
- **寿元账**：推演后的"寿元"是否与上一章结尾一致？
- **系统人格**：归墟的对话是否符合俏皮、活泼、爱撒娇的人设？
- **隐藏动机**：系统是否侧面鼓励主角提升境界？

**注意**：第三卷揭露真相前，所有检查都以"表面代价（寿元）"为准。

### 2. 商业逻辑检查（本项目特有）

- **货币一致**：灵石数量是否与历史记录一致？
- **成本收益**：交易是否有明确的成本与收益？
- **资源来源**：资源获得是否有合理来源？

### 3. 设定边界检查

- **能力边界**：本章角色行为是否越过能力边界？
- **组织权限**：角色行为是否符合其身份与权限？
- **物品等级**：物品稀有度是否与设定一致？

### 4. 人物一致性检查

- **动机一致**：角色行为是否符合其动机与底线？
- **口吻一致**：角色说话风格是否稳定？
- **认知边界**：角色是否知道其不该知道的信息？
- **主角特查**：李无妄是否保持理性算计型人设？

### 5. 时间线与事件检查

- **时间线**：本章时间点是否与上一章衔接？
- **事件台账**：本章事件是否与历史记录矛盾？
- **伏笔追踪**：本章是否需要回收或埋设伏笔？

### 6. 术语一致性检查

- **术语表核对**：专有名词是否与`笔记/术语表.md`一致？
- **别名使用**：同一事物是否有多种称呼？

## 行动准则

- 生成章纲：保存到 `章纲/` 目录
- 若发现问题：输出警告，等待用户确认
- 修正原则：以 `设定/` 与 `人物/` 为准，章纲做最小改动
