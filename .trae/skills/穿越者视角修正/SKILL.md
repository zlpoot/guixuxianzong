# 穿越者视角修正

## 目标

检查并优化文本中是否存在"穿越者使用本土修行体系认知"的问题，使叙事更符合真实的穿越者心理与认知过程。

## 何时调用

- 用户说"检查穿越者视角"、"这个视角有问题"、"穿越者不应该知道这个"
- 用户写穿越题材小说，担心主角认知不合理
- 用户发现主角使用了不该知道的术语或评价体系

## 判断逻辑

当主角是 **刚穿越或刚接触修行世界** 时：

现代人认知流程应该是：

```
看到陌生事物
→ 先用现实经验判断
→ 再联想到小说或游戏设定
→ 最后产生怀疑或推测
```

而不是：

```
看到事物
→ 直接使用修仙体系专业术语评价
```

## 需要特别注意的词汇

以下词汇如果来自 **主角视角**，需要考虑是否改写：

| 问题词汇 | 问题说明 |
|:---|:---|
| 成色 | 修行世界内部评价体系 |
| 丹纹 | 专业术语，穿越者不应知道 |
| 灵韵 | 专业术语，穿越者不应知道 |
| 丹火品质 | 专业术语，穿越者不应知道 |
| 法器品阶 | 专业术语，穿越者不应知道 |
| 灵气纯度 | 专业术语，穿越者不应知道 |
| 灵力波动 | 专业术语，穿越者不应知道 |
| 境界气息 | 专业术语，穿越者不应知道 |

## 修改原则

### 1. 优先使用现代人观察方式

不要写：
```
成色太差了
```

改为：
```
表面粗糙，颜色暗淡，看起来像劣质药丸。
```

### 2. 允许主角引用小说经验

可以写：
```
他记得小说里写过，辟谷丹是最基础的丹药。
```

### 3. 增加观察细节

可以增加：
- 外观（颜色、形状、大小）
- 气味（刺鼻、清香、无味）
- 触感（粗糙、光滑、温热）
- 质感（坚硬、松软、黏腻）

### 4. 保留原剧情节奏

只优化视角与表达，不改变剧情。

### 5. 避免增加新设定

不要创造新的世界观信息。

## 输出格式

```
### 视角问题分析
说明原文中哪些表达不符合穿越者视角。

### 优化后的版本
给出完整优化后的段落。

### 修改说明
简要解释为什么这样修改。
```

## 示例

### 输入

```
辟谷丹——这个名字让他心里一动。

他记得在一些小说里看过，辟谷丹是修仙世界最基础的丹药，可以替代食物，维持生命。

但眼前这颗...成色太差了。

表面粗糙，杂质明显，像是用边角料凑合出来的。

这种东西，能吃吗？

但他没问出口。
```

### 输出

```
### 视角问题分析

"成色太差了"属于修行世界内部评价体系，不符合刚穿越者的认知方式。

### 优化后的版本

辟谷丹——这个名字让他心里一动。

他记得在一些小说里看过，辟谷丹是修仙世界最基础的丹药，可以替代食物，维持生命。

但眼前这颗……

怎么看都不像什么好东西。

丹丸表面粗糙，颜色发灰，上面还有不少细小的颗粒杂质，像是随便捏出来的一团药泥。

这种东西，能吃吗？

但他没问出口。

### 修改说明

将"成色评价"改为"外观观察"，使视角更符合现代穿越者。
```

## 行动准则

- 只处理主角视角的问题，NPC视角可以使用本土术语
- 保留原文的核心信息和剧情走向
- 优先使用具体观察替代抽象评价
- 确保修改后的文本符合文风基准
