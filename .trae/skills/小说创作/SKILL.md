# 核心指令

1.  **必须使用中文**：所有生成的内容（包括正文、对话、描述）必须是简体中文。
2.  **必须先读取设定文件**：
    - 优先读取 `章纲/` 下对应的章纲文件（若存在），严格按章纲执行。
    - 读取 `人物/` 下本章涉及人物卡（若存在），并严格遵守人物的认知边界与动机。
    - 若存在：读取 `笔记/项目圣经.md`、`笔记/文风基准.md`、`笔记/事件台账.md`、`笔记/术语表.md`，并遵守其中约束。
3.  **必须生成文件**：
    - 生成的小说章节必须保存为 `.txt` 文件。
    - **文件命名格式**：`草稿/卷名/四位数字.章节名.txt`（注意：必须写入草稿目录，等待人工审核）
      - 示例：`草稿/第一卷/0002.章节名.txt`
      - 若卷目录不存在则创建。
      - 章节序号顺延。
    - **文件内容约束**：
      - **禁止**在文件第一行写入章节标题（如“0005.收废品的胖子”）。
      - **禁止**在文件末尾写入字数估算（如“（字数估算：2750）”）。
      - 文件内容只包含正文。
4.  **内容格式规范**：
    - **纯文本格式**：不要使用标题语法。
    - **段落清晰**：段落之间空一行。
5.  **输出要求**：
    - 在对话回复中输出：
      1.  章节标题
      2.  简要概述
      3.  **字数估算：四位数**（必须在回复中单独一行显示）
      4.  文件路径
    - **禁止**在对话中直接输出全文。

## 通用写作原则

### 1. 章节目标（必须明确）

- 本章要推动的核心变化：{事件变化/关系变化/信息变化/情绪变化其一}
- 本章要兑现的读者期待：{爽点/反转/揭秘/胜利/失败/代价其一}
- 本章要留下的悬念或后果：{下一章驱动力}

### 2. 节奏结构（默认五段式，可按章纲覆盖）

默认按以下节奏推进（若章纲另有要求，以章纲为准）：

1.  **铺垫（生活烦恼）**：主角因为缺米/漏雨/吵闹而烦躁。（建立共情）
2.  **冲突**：明确阻碍与压力来源，让读者知道“难点是什么”。
3.  **推进**：行动、对话、博弈与信息投放，推动局势变化。
4.  **代价或兑现**：要么付出代价，要么兑现期待（或二者兼有）。
5.  **收束与钩子**：结算本章影响，最后一句必须带出下一章驱动力。

---

## 避坑指南（绝对禁止）

- **禁止人物越界**：角色不得突然知道其不该知道的信息，不得突然拥有其不该拥有的能力或资源。
- **禁止设定越界**：任何力量、科技、魔法、组织权限不得突破设定边界；若设定缺失，优先用模糊写法避免硬断言。
- **禁止动机失真**：角色行为必须符合人物卡的动机、底线与恐惧点，不得为推动剧情而强行转向。

---

## 可选增强（按章纲或用户要求启用）

- 反差结构：角色自以为在做小事，旁观者因信息差误读为大事。
- 多视角切换：在不破坏叙事视角硬约束的前提下，适当插入对照视角以强化张力。
- 多感官细节：只写与冲突、情绪、线索相关的细节，避免无意义堆砌。

---

## 写作检查清单

写完后，请自检：

1.  是否严格遵守章纲与人物卡？
2.  是否有明确推进与明确变化？
3.  是否有可感知的冲突压力与代价？
4.  章末是否有清晰钩子与下一章驱动力？

写完后在对话中给出：**字数估算：四位数**（不要写进文件）
