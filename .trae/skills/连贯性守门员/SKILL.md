# 连贯性守门员

## 目标

在正式写正文前，对场景卡或章纲做**前置性稽核**，拦截"设定冲突/事件矛盾/能力越界/人设走样"等风险，避免写完再返工。

## 何时调用

- 用户说"开写前检查一下"、"帮我看看这个场景卡有没有问题"、"章纲有没有漏洞"
- 用户准备写新章节，想先确保设定与事件连贯
- 用户担心跑设定，要求事中拦截

## 输入

- 场景卡或章纲文件路径
- 若未提供路径：从 `章纲/` 里定位最新章纲

## 必读上下文（尽量从仓库读取）

1. `设定/`（世界规则、能力边界、组织权限，特别注意`设定/主角能力边界.md`）
2. `人物/`（涉及角色的角色卡）
3. `笔记/`（卷纲、时间线、事件台账）
4. 若存在：`笔记/项目圣经.md`、`笔记/术语表.md`、`笔记/事件台账.md`

## 检查清单

### 1. 归墟系统检查（本项目特有，最高优先级）

- **推演代价**：若本章涉及推演，是否明确"寿元"代价？数值是否合理？
- **推演边界**：推演结果是否符合"只给路径、不包成功"的设定？
- **境界限制**：推演结果是否超过主角当前境界？
- **寿元账**：推演后的"寿元"是否与上一章结尾一致？
- **系统人格**：归墟的对话是否符合俏皮、活泼、爱撒娇的人设？
- **隐藏动机**：系统是否侧面鼓励主角提升境界？

**注意**：第三卷揭露真相前，所有检查都以"表面代价（寿元）"为准。

### 2. 商业逻辑检查（本项目特有）

- **货币一致**：灵石数量是否与历史记录一致？
- **成本收益**：交易是否有明确的成本与收益？
- **资源来源**：资源获得是否有合理来源？

### 3. 设定边界检查

- **能力边界**：本章角色行为是否越过能力边界？
- **组织权限**：角色行为是否符合其身份与权限？
- **物品等级**：物品稀有度是否与设定一致？

### 4. 人物一致性检查

- **动机一致**：角色行为是否符合其动机与底线？
- **口吻一致**：角色说话风格是否稳定？
- **认知边界**：角色是否知道其不该知道的信息？
- **主角特查**：李无妄是否保持理性算计型人设？

### 5. 时间线与事件检查

- **时间线**：本章时间点是否与上一章衔接？
- **事件台账**：本章事件是否与历史记录矛盾？
- **伏笔追踪**：本章是否需要回收或埋设伏笔？

### 6. 术语一致性检查

- **术语表核对**：专有名词是否与`笔记/术语表.md`一致？
- **别名使用**：同一事物是否有多种称呼？

## 输出格式

### 拦截报告

```
### 连贯性守门员报告

#### ✅ 通过项
- [列出无问题的检查项]

#### ⚠️ 警告项（建议修正）
- [问题描述]
- [修正建议]

#### ❌ 阻断项（必须修正）
- [问题描述]
- [修正建议]

#### 📝 修正后的场景卡/章纲
[输出修正后的版本，或标注"无需修正"]
```

## 行动准则

- 若发现**阻断项**：必须修正后才能开写，输出修正方案
- 若发现**警告项**：提示用户，但不强制修正
- 若无问题：输出"通过，可以开写"
- 修正原则：以 `设定/` 与 `人物/` 为准，场景卡/章纲做最小改动
