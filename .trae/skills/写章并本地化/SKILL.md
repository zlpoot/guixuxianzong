# 写章并本地化

## 目标

一键生成单章草稿，并在写完后自动更新人物卡、事件台账、术语表等本地化记录，确保设定与正文同步。

## 何时调用

- 用户说"出本章并归档"、"写完自动更新人物与台账"、"只调用整合技能"
- 用户需要一键完成"写章+归档"全流程

## 输入

- 章纲文件路径（可选）
- 若未提供路径：从 `章纲/` 里定位最新章纲

## 必读上下文（尽量从仓库读取）

1. `章纲/`（本章章纲）
2. `设定/`（世界规则、能力边界，特别注意`设定/主角能力边界.md`）
3. `人物/`（涉及角色的角色卡）
4. `笔记/`（卷纲、时间线、事件台账、伏笔追踪）
5. 若存在：`笔记/项目圣经.md`、`笔记/术语表.md`、`笔记/文风基准.md`

## 执行流程

### 第一步：前置检查

1. 读取章纲，确认本章核心事件与目标
2. 读取设定与人物卡，确认能力边界与人设
3. 读取事件台账与伏笔追踪，确认时间线与伏笔状态
4. 若发现问题：输出警告，等待用户确认

### 第二步：生成草稿

1. 根据章纲生成草稿
2. 确保符合文风基准
3. 确保符合设定边界
4. 确保符合人物人设

### 第三步：归档更新

1. 更新事件台账：添加本章事件
2. 更新人物卡：添加本章人物变化
3. 更新术语表：添加新术语
4. 更新伏笔追踪：添加新伏笔或更新伏笔状态
5. 更新项目圣经：更新时间线与已发生事件

### 第四步：输出报告

输出《写章并归档报告》，包含：
- 草稿位置
- 归档更新内容
- 注意事项

## 检查清单

### 1. 归墟系统检查（本项目特有，最高优先级）

- **推演代价**：若本章涉及推演，是否明确"寿元"代价？数值是否合理？
- **推演边界**：推演结果是否符合"只给路径、不包成功"的设定？
- **境界限制**：推演结果是否超过主角当前境界？
- **寿元账**：推演后的"寿元"是否与上一章结尾一致？
- **系统人格**：归墟的对话是否符合俏皮、活泼、爱撒娇的人设？
- **隐藏动机**：系统是否侧面鼓励主角提升境界？

**注意**：第三卷揭露真相前，所有检查都以"表面代价（寿元）"为准。

### 2. 商业逻辑检查（本项目特有）

- **货币一致**：灵石数量是否与历史记录一致？
- **成本收益**：交易是否有明确的成本与收益？
- **资源来源**：资源获得是否有合理来源？

### 3. 设定边界检查

- **能力边界**：本章角色行为是否越过能力边界？
- **组织权限**：角色行为是否符合其身份与权限？
- **物品等级**：物品稀有度是否与设定一致？

### 4. 人物一致性检查

- **动机一致**：角色行为是否符合其动机与底线？
- **口吻一致**：角色说话风格是否稳定？
- **认知边界**：角色是否知道其不该知道的信息？
- **主角特查**：李无妄是否保持理性算计型人设？

### 5. 时间线与事件检查

- **时间线**：本章时间点是否与上一章衔接？
- **事件台账**：本章事件是否与历史记录矛盾？
- **伏笔追踪**：本章是否需要回收或埋设伏笔？

### 6. 术语一致性检查

- **术语表核对**：专有名词是否与`笔记/术语表.md`一致？
- **别名使用**：同一事物是否有多种称呼？

## 输出格式

### 写章并归档报告

```
### 写章并归档报告

#### 📝 草稿位置
- [草稿文件路径]

#### 📂 归档更新
- **事件台账**：[添加的事件]
- **人物卡**：[更新的角色]
- **术语表**：[添加的术语]
- **伏笔追踪**：[添加/更新的伏笔]
- **项目圣经**：[更新的内容]

#### ⚠️ 注意事项
- [需要用户确认的问题]

#### 📊 寿元账（若本章涉及推演）
- 推演前寿元：[数值]
- 本次消耗：[数值]
- 推演后寿元：[数值]
```

## 行动准则

- 生成草稿：保存到 `草稿/` 目录
- 归档更新：更新对应的 `笔记/` 文件
- 若发现问题：输出警告，但不中断流程
- 修正原则：以 `设定/` 与 `人物/` 为准，草稿做最小改动
