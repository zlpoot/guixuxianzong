# 伏笔管理

## 目标

把伏笔从大纲/正文中抽取成台账，标注埋点与回收计划，确保伏笔不被遗忘、逻辑自洽。

## 何时调用

- 用户说"帮我梳理一下伏笔"、"检查有没有遗漏的伏笔"、"回收这个伏笔"
- 用户要埋设新伏笔
- 用户要回收旧伏笔
- 用户担心伏笔吃书

## 输入

- 大纲/正文文件路径（可选）
- 若未提供路径：从 `大纲/` 和 `草稿/` 里定位最新内容

## 必读上下文（尽量从仓库读取）

1. `笔记/伏笔追踪.md`（现有伏笔台账）
2. `大纲/`（卷纲、章纲）
3. `草稿/`（正文）
4. 若存在：`笔记/项目圣经.md`、`笔记/事件台账.md`

## 伏笔台账格式

| 伏笔名称 | 埋点位置 | 埋点内容 | 回收位置 | 回收内容 | 状态 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| 归墟系统真相 | 第一卷0002 | 系统以寿元为代价进行推演 | 第三卷 | 揭露寿元消耗是假的，实际消耗悟道石算力 | 未回收 |
| 黑石矿场背后的势力链 | 第一卷0001 | 矿场压榨矿奴，配额与惩罚口径 | 第二卷 | 揭露矿场、丹药、坊市渠道的勾连关系 | 未回收 |
| 早期欠条与名册 | 第一卷0003 | 李无妄开始记录矿区账本 | 第二卷 | 演变成组织、股份或控制工具 | 未回收 |
| 工业化副作用 | 第二卷 | 归墟商会开始工业化生产 | 第三卷 | 灵脉异常与灵气污染的成因、代价与解决方案 | 未回收 |

## 检查清单

### 1. 归墟系统伏笔（本项目特有，最高优先级）

- **系统真相**：是否埋设了"寿元消耗是假的"的伏笔？
- **系统来源**：是否埋设了"系统由第一任天衍宗宗主创造"的伏笔？
- **悟道石**：是否埋设了"悟道石是系统实际能源"的伏笔？
- **系统人格**：归墟的隐藏动机（鼓励主角提升境界）是否通过对话暗示？

### 2. 商业伏笔（本项目特有）

- **资源来源**：主角获得的资源是否埋设了合理来源？
- **成本收益**：交易的成本与收益是否埋设了伏笔？
- **势力关系**：不同势力之间的关系是否埋设了伏笔？

### 3. 人物伏笔

- **动机伏笔**：角色的动机是否埋设了伏笔？
- **底线伏笔**：角色的底线是否埋设了伏笔？
- **恐惧点伏笔**：角色的恐惧点是否埋设了伏笔？

### 4. 世界伏笔

- **规则伏笔**：世界规则是否埋设了伏笔？
- **地理伏笔**：地理环境是否埋设了伏笔？
- **历史伏笔**：历史事件是否埋设了伏笔？

## 输出格式

### 伏笔管理报告

```
### 伏笔管理报告

#### 📌 新增伏笔
- [列出从大纲/正文中抽取的新伏笔]

#### ✅ 已回收伏笔
- [列出已回收的伏笔]

#### ⚠️ 遗漏伏笔（建议补充）
- [列出应该埋设但未埋设的伏笔]

#### 📝 更新后的伏笔台账
[输出更新后的伏笔台账]
```

## 行动准则

- 新增伏笔：从大纲/正文中抽取，添加到 `笔记/伏笔追踪.md`
- 回收伏笔：更新伏笔状态，标注回收位置与内容
- 遗漏伏笔：提示用户，建议补充埋设点
- 修正原则：以 `笔记/伏笔追踪.md` 为准，确保伏笔台账完整
