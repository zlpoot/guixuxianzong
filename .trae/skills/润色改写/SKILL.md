# 润色改写

## 目标

在不改变既定剧情走向的前提下，提升可读性与叙事节奏：更清晰的信息投放、更有效的对话推进、更有力的章末钩子。
核心逻辑：以“文风基准”为准，在不改大事件走向的前提下，提升节奏、信息密度、冲突强度与章末钩子拉力。

## 何时调用

- 用户说“润色/改写/提节奏/提爽点/统一文风”
- 用户拿到初稿后要变成可发布版本
- 用户想把某条行动链写得更顺、更有张力、更有回味

## 必读上下文

- 与本章相关的人物卡（`人物/`）
- `大纲.md`（特别是“爽点公式”和“写作硬约束”）
- 若存在：`笔记/项目圣经.md`、`笔记/文风基准.md`、`笔记/术语表.md`

## 输出方式（两阶段）

1. 先给“改动清单”（不超过 8 条），说明要改的方向
2. 再给“可直接替换的改写稿”
   - 若用户提供了章节文件路径：直接把改写稿写回该章节文件
     - **注意**：写回文件时，**严禁**写入章节标题和字数估算（只保留正文）。
   - 若用户只给片段：只输出改写片段，不改文件

## 润色方向（通用）

1.  **节奏提速**：
    - 删掉不推进事件、不加深关系、不投放信息的段落。
    - 把冲突与压力点尽量前置，减少铺垫绕圈。
2.  **信息密度与可读性**：
    - 让每段都有明确作用（推进、揭示、反转、铺垫其一）。
    - 把解释性段落改成“通过行动与对话展示”。
3.  **人物与口吻**：
    - 台词贴合人物卡；同一角色保持稳定句式与用词。
    - 心理活动服务于动机与选择，不用来灌水。
4.  **冲突升级**：
    - 让对手有明确诉求与手段，让阻碍具备“逼迫行动”的力度。
5.  **钩子必查**：
    - 章末最后一句话必须引出下一章驱动力（追查、请求、灾变、榜单、误会扩散等之一）。

## 改写验收项

- [ ] 每 300-600 字有一次明确推进（事件/信息/情绪/反转其一）
- [ ] 没有任何一句废话（纯为了凑字数的环境描写删掉）
- [ ] 角色不越界：认知、动机、能力边界稳定
- [ ] 章末钩子明确有力
