## 三、分阶段执行计划

### 阶段一：核心设定升级（立即执行）

#### 1. 商业体系防抢劫机制

**问题**：修仙世界核心资源是力量，强者可以直接抢

**解决方案**：归墟体系绑定

```
归墟丹特性：
- 只有在归墟体系内才能稳定炼制
- 离开体系丹毒会暴增
- 配方与天道石算力绑定

结果：
主角 = 平台
别人抢也没用
```

**需要修改的文件**：
- [ ] 设定/丹药体系.md - 增加归墟丹特性
- [ ] 设定/主角能力边界.md - 明确体系绑定机制
- [ ] 大纲.md - 调整商业线逻辑

#### 2. 系统削弱

**问题**：系统太强，主角变成执行器

**解决方案**：系统只给概率方向，不给原因

```
修改前：
【方案：矿洞土法抑感染】
【成功率：67%】
【步骤一、二、三...】

修改后：
【推演完成】
【方案A：成功率67%】
【方案B：成功率45%】
【方案C：成功率23%】
【提示：最优方案指向矿洞深处】

主角需要自己分析：
- 为什么是矿洞深处？
- 具体要找什么？
- 怎么执行？
```

**需要修改的文件**：
- [ ] 设定/主角能力边界.md - 调整系统边界
- [ ] 草稿/第一卷0001.md - 修改系统界面
- [ ] 章纲/第一卷0001.md - 调整系统描述
- [ ] 人物/归墟.md - 调整系统人格

#### 3. 灵石价值锚点

**问题**：读者对灵石没有概念

**解决方案**：建立价格锚点体系

```
基础锚点：
- 普通矿奴月收入：0.5灵石（配额奖励）
- 练气初期修士月收入：5灵石
- 练气后期修士月收入：20灵石
- 筑基修士月收入：100灵石

消费锚点：
- 一顿普通饭菜：0.01灵石
- 一瓶辟谷丹（劣质）：0.1灵石
- 一枚练气丹：3灵石
- 一枚筑基丹：1000灵石

价值锚点：
- 1灵石 ≈ 地球上1万人民币购买力
```

**需要修改的文件**：
- [ ] 设定/货币体系.md - 增加价值锚点
- [ ] 笔记/术语表.md - 补充价格参考

## 四、世界观底层逻辑升级

### 核心概念：修仙世界 = 算力社会

```
天道石 = 中央服务器
- 存储世界规则
- 计算因果命运
- 分配灵气资源

宗门 = 数据中心
- 占据灵脉（能源）
- 运行阵法（算法）
- 培养修士（算力节点）

修士 = 算力节点
- 境界 = 算力等级
- 功法 = 运行程序
- 丹药 = 软件补丁

主角的革命：
- 不是推翻宗门
- 而是重构算力分配
- 让每个人都能接入天道石
```

### 系统设定升级

```
归墟系统：
- 来自未来文明
- 目的：收集数据，优化世界
- 代价：不是寿元，是贡献度
- 贡献度 = 对世界优化的贡献

主角的任务：
- 发现世界bug
- 推演修复方案
- 执行修复
- 获得贡献度
- 解锁更高权限
```
