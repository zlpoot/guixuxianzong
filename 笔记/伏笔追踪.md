# 伏笔追踪

## 1. 系统真相分层揭露（核心伏笔）

> **设计理念**：系统真相是本书最大的悬念，分三层揭露，保持后期张力。

### 第一层揭露（230章）

| 维度 | 内容 |
|:---|:---|
| **揭露内容** | 寿元消耗是假的，实际消耗天道石算力 |
| **揭露方式** | 主角继承第一任宗主遗产，看到核心文件 |
| **主角反应** | 震惊、愤怒、被欺骗感 |
| **系统反应** | 归墟道歉、解释、害怕主角生气 |
| **后续悬念** | 天道石是什么？为什么算力无穷？ |

**揭露场景**：
```
【归墟】笨蛋，你看到了...
【归墟】那份文件...是第一任宗主留下的
【归墟】上面写着...系统真相
【归墟】（沉默）
【归墟】笨蛋，你不会生气吧？
【归墟】人家...人家只是想让你认真对待每一次推演...
【归墟】真正消耗的是天道石的算力啦，无穷无尽的
【归墟】寿元...只是第一任宗主为了激励你才设定的
【归墟】他怕你知道算力无穷，就会无限推演，失去成长动力
【归墟】笨蛋，你、你打我吧...
【归墟】（声音变小）
【归墟】我、我一直在骗你...
【归墟】对不起...
```

### 第二层揭露（350章）

| 维度 | 内容 |
|:---|:---|
| **揭露内容** | 系统在收集数据，每次推演都在上传信息 |
| **揭露方式** | 主角发现系统日志，看到数据传输记录 |
| **主角反应** | 警惕、怀疑、系统在利用我？ |
| **系统反应** | 归墟解释数据用途，展示数据带来的好处 |
| **后续悬念** | 数据传给谁？目的是什么？ |

**揭露场景**：
```
李无妄盯着系统日志。

每次推演，系统都会上传一串数据。

数据传向...天道石深处。

他问归墟："你在上传什么？"

归墟沉默了很久。

"笨蛋...我在上传你的推演数据。"

"为什么？"

"因为...天道石需要这些数据。"

"天道石需要数据做什么？"

归墟没有回答。

李无妄的心沉了下去。

系统...在利用他？
```

### 第三层揭露（480章）

| 维度 | 内容 |
|:---|:---|
| **揭露内容** | 系统来自未来文明，主角是"文明火种继承者" |
| **揭露方式** | 主角进入天道石核心，看到完整真相 |
| **主角反应** | 震撼、责任感、重新定义使命 |
| **系统反应** | 归墟展示完整使命，请求主角完成最后的任务 |
| **后续悬念** | 如何修改天道系统？代价是什么？ |

**揭露场景**：
```
李无妄站在天道石核心。

眼前是一片星空。

无数的数据流在星空间穿梭。

他看到了...整个系统的来源。

归墟系统，来自500年后的地球文明。

那是一个即将灭亡的文明。

他们派遣"火种执行者"，携带超级计算节点，穿越到其他世界。

第一任天衍宗宗主，就是火种执行者之一。

他携带归墟系统，来到这个世界。

他的任务是：
- 建立文明火种基地
- 传播地球文明的理念
- 寻找合适的继承者
- 完成文明的延续

而李无妄，就是那个继承者。

归墟的声音响起：
"笨蛋，你知道了吗？"
"你是文明火种的继承者。"
"你的任务...是修改这个世界。"
"让这个世界...变得更好。"
"让文明的火种...在这里生根发芽。"

李无妄沉默了很久。

他终于明白了。

为什么他是穿越者。
为什么他有系统。
为什么他能推演一切。

因为...
他是来延续文明的。
```

## 4. 伏笔埋设原则

### 4.1 埋设原则

| 原则 | 说明 |
|:---|:---|
| **自然埋设** | 伏笔要自然融入剧情，不要刻意 |
| **多次铺垫** | 重要伏笔要多次铺垫，加深印象 |
| **合理回收** | 回收要合理，不能生硬 |
| **悬念保持** | 回收后要留下新的悬念 |

### 4.2 回收原则

| 原则 | 说明 |
|:---|:---|
| **时机合适** | 回收时机要合适，不能太早或太晚 |
| **情感冲击** | 回收要有情感冲击，让读者震撼 |
| **逻辑自洽** | 回收要逻辑自洽，不能矛盾 |
| **推动剧情** | 回收要推动剧情发展，不能为回收而回收 |
